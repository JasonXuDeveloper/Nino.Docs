This page covers weak version tolerance and custom constructors.

## Weak Version Tolerance [#weak-version-tolerance]

Nino supports a weaker, more flexible kind of version tolerance: you can add new fields to a managed `[NinoType]` and still deserialize data serialized by the old version. This is typically used for save games, as a game adds members to its save data over its versions.

The mechanism has several restrictions:
- New members can only be added at the end of the type.
- Members must be ordered explicitly with `[NinoType(false)]` and `[NinoMember(order)]`, so that the new members come after the old ones.
- Existing members cannot be removed, and changing their types is restricted as well (see [Version Compatibility](/en/docs/v2/types#version-compatibility)).
- You cannot define new serializable types, unless the TypeId of the version-tolerant type in Nino's generated code stays the same, for example:
  ```csharp
  case 26:
  {
      // use Nino.UnitTests.SaveData.SaveData()
  ```
  After adding a serializable type, check that the TypeId of the version-tolerant type (`SaveData`, here `26`) has not changed.

Weak version tolerance is off by default. To enable it, define the symbol `WEAK_VERSION_TOLERANCE` in your project.

<Callout type="warn">

Enabling it makes deserialization about 5% slower.

</Callout>

### Usage [#weak-version-tolerance-usage]

```csharp title="SaveData.cs"
// WEAK_VERSION_TOLERANCE is defined
[NinoType(false)]
public class SaveData
{
    [NinoMember(1)] public int Id;
    [NinoMember(2)] public string Name;
    [NinoMember(3)] public DateTime NewField1; // [!code ++]
    [NinoMember(4)] public Generic<int> NewField2; // [!code ++]
}
```

This adds two fields, `NewField1` and `NewField2`, to `SaveData`. `[NinoType(false)]` and `[NinoMember(order)]` place them after the old fields, so data serialized by the old version still deserializes correctly (with `WEAK_VERSION_TOLERANCE` defined).

<Callout type="info">

This is one of Nino's unit tests, so it is verified to work.

</Callout>

## Custom Constructors [#custom-constructors]

Nino can deserialize an object through a constructor of your choice. Use it to run extra code while an object is deserialized, for example to initialize fields or properties that are not serialized. For records, Nino can use either the primary constructor or a custom one.

### Usage [#constructor-usage]

The attribute below passes the members `Field1, Field2, ...` as the arguments of the constructor it marks:

```csharp
[NinoConstructor(nameof(Field1), nameof(Field2), ...)]
```

Without the attribute, Nino picks a constructor itself:

| Type | Constructor used by default |
| --- | --- |
| `record` | The primary constructor. |
| `class` | The **first public constructor** that is parameterless, or whose parameters all have the same names as the fields or properties to deserialize. |
| `struct` | The parameterless constructor (a struct always has one). |

When that constructor is not suitable, mark the one to use with `[NinoConstructor]`.

### Restrictions [#restrictions]
- The constructor must be `public`.
- It must have as many parameters as the names listed in `[NinoConstructor]`.
- Each name in `[NinoConstructor]` must match (ignoring case) a field or property of the class, struct or record that is deserialized, so that member must be serialized in the first place.
- The names in `[NinoConstructor]` are the members passed to the constructor, in order.

### Examples [#constructor-examples]

<Tabs items={["Several constructors", "Primary constructor", "Not the primary constructor"]}>
<Tab value="Several constructors">

```csharp
[NinoType]
public record SimpleRecord
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    public SimpleRecord()
    {
        Id = 0;
        Name = string.Empty;
        CreateTime = DateTime.MinValue;
    }

    [NinoConstructor(nameof(Id), nameof(Name))] // [!code highlight]
    public SimpleRecord(int id, string name)
    {
        Id = id;
        Name = name;
        CreateTime = DateTime.Now;
    }
}
```

</Tab>
<Tab value="Primary constructor">

```csharp
[NinoType]
public record SimpleRecord2(int Id, string Name, DateTime CreateTime); // [!code highlight]

[NinoType]
public record SimpleRecord4(int Id, string Name, DateTime CreateTime) // used // [!code highlight]
{
    [NinoIgnore] public bool Flag;

    public int ShouldNotIgnore;

    // Nino does not use this one // [!code highlight]
    public SimpleRecord4() : this(0, "", DateTime.MinValue)
    {
    }
}
```

</Tab>
<Tab value="Not the primary constructor">

```csharp
[NinoType]
public record SimpleRecord5(int Id, string Name, DateTime CreateTime) // not used // [!code highlight]
{
    [NinoIgnore] public bool Flag;

    public int ShouldNotIgnore;

    // Nino uses this one, which discards the primary constructor values when deserializing
    [NinoConstructor] // [!code highlight]
    public SimpleRecord5() : this(0, "", DateTime.MinValue)
    {
    }
}
```

</Tab>
</Tabs>

Custom constructors work for classes and structs too:

<Tabs items={["Struct with a parameterized constructor", "Class with a parameterized constructor"]}>
<Tab value="Struct with a parameterized constructor">

```csharp
[NinoType]
public struct SimpleStruct
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    // used to create the struct when deserializing
    [NinoConstructor(nameof(Id), nameof(Name), nameof(CreateTime))] // [!code highlight]
    public SimpleStruct(int a, string b, DateTime c)
    {
        Id = a;
        Name = b;
        CreateTime = c;
    }
}
```

</Tab>
<Tab value="Class with a parameterized constructor">

```csharp
[NinoType]
public class SimpleClassWithConstructor
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    // No [NinoConstructor] needed: this is the only public constructor,
    // and its parameters match the member names, so Nino uses it
    public SimpleClassWithConstructor(int id, string name, DateTime createTime) // [!code highlight]
    {
        Id = id;
        Name = name;
        CreateTime = createTime;
    }
}
```

</Tab>
</Tabs>
