<Cards>
  <Card title="Faster than fast">
    Serialization and deserialization runs significantly faster than JSON, Protobuf, MessagePack, etc. trivial solutions

    *Most benchmark results are better than MemoryPack and other similar solutions*
  </Card>
  <Card title="Easy to use">
    By using Source Generator, Nino automatically generates serialization and deserialization functions while the user is writing the program

    *The generated code is transparent and support non JIT platforms like NativeAOT natively*
  </Card>
  <Card title="Powerful yet versatile">
    Support serializing and deserializing various data structures, i.e. primitives, structs, classes, collections, dictionaries, etc.

    *Besides Nino also supports serializing and deserializing objects with polymorphism*
  </Card>
</Cards>
