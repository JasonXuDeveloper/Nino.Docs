## What Is Nino? [#what-is-nino]

Nino is a practical, high-performance serialization library for any C# project, including but not limited to .NET Core apps and Unity or Godot games. Mark a type with `[NinoType]`, and a source generator writes its serialization code while you write your program. At run time you call the generated `Serializer` and `Deserializer`:

```csharp title="Program.cs"
[NinoType]
public class ObjClass
{
    public int Id;
    public string Name { get; set; }
}

byte[] bytes = Serializer.Serialize(obj);
Deserializer.Deserialize(bytes, out ObjClass copy);
```

## Why Nino v2 [#why-nino-v2]

- **Faster than fast.** Serialization and deserialization are much faster than common solutions such as JSON, Protobuf and MessagePack, and most benchmark results beat MemoryPack and similar libraries. See [Benchmarks](/en/docs/v2/perf).
- **Easy to use.** The source generator writes the serialization and deserialization code while you write your program. The generated code is plain C# you can read, and it runs on platforms without a JIT, such as NativeAOT.
- **Powerful yet versatile.** Primitives, structs, classes, collections, dictionaries and more, including polymorphic types. See [Supported Types](/en/docs/v2/types).

## Newer Version [#newer-version]

Nino v2 is archived. The current version is [Nino v4](/en/docs/v4); its binary format is not compatible with v2 or v3. To move from v2 to v3, see [Versioning](/en/docs/v3/versioning#migrating-from-nino-v2).
