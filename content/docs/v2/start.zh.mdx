Nino v2 在 .NET 项目中以 NuGet 包安装，在 Unity 中以 `.unitypackage` 导入，两者都包含运行时库和源生成器。

## 安装 [#installation]

<Tabs groupId="platform" persist items={['.NET', 'Unity']}>
<Tab value=".NET">

```shell
dotnet add package Nino
```

详见 [.NET 项目](/zh/docs/v2/start#net-project)。

</Tab>
<Tab value="Unity">

从 [GitHub Releases](https://github.com/JasonXuDeveloper/Nino/releases) 下载 `Nino.unitypackage` 并导入。

详见 [Unity 项目](/zh/docs/v2/start#unity-project)。

</Tab>
</Tabs>

### .NET 项目 [#net-project]

<Callout type="info">

Nino 支持 .NET 5.0 及以上版本，或 .NET Standard 2.0 及以上版本的项目。

</Callout>

- 在 Visual Studio 或 Rider 的 NuGet 包管理器中搜索 `Nino` 并安装
- 或者使用 `dotnet` 命令行：
    ```shell
    dotnet add package Nino
    ```

<Callout type="info">

Nino 需要两个 NuGet 包：`Nino.Generator` 和 `Nino.Serialization`，缺一不可。安装 `Nino` 会自动装上这两个包。

</Callout>

<Callout type="warn">

这种方式不支持 .NET Framework 项目，也不支持不能运行源生成器的 IDE（如 Visual Studio Code）。

</Callout>

### Unity 项目 [#unity-project]

<Callout type="info">

Nino 支持 Unity 2022.3 及以上版本，可以发布到任意平台。

GitHub 上的 `Nino_Unity` 示例项目演示了如何在 Unity 中使用 Nino，建议先把它跑起来。

</Callout>

<Steps>
<Step>

### 下载插件 [#download-the-plugin]

在 [Releases](https://github.com/JasonXuDeveloper/Nino/releases) 页面找到需要的 Nino 版本，下载对应的 `Nino.unitypackage`。

</Step>
<Step>

### 安装 `Microsoft.CodeAnalysis` [#install-microsoftcodeanalysis]

Unity 中的源生成器需要 `Microsoft.CodeAnalysis` NuGet 包（最新版即可）。可以在 Unity 项目目录（`Assets` 所在的目录）下安装，例如：

```shell
dotnet add package Microsoft.CodeAnalysis.CSharp --version 4.10.0
```

</Step>
<Step>

### 导入插件 [#import-the-plugin]

把下载好的 `Nino.unitypackage` 导入 Unity 项目。

</Step>
<Step>

### 把 Nino 移到带 `asmdef` 的目录 [#move-nino-into-an-asmdef]

把导入的 Nino 文件夹移到一个带 `asmdef` 的目录里（如 `Nino_Unity` 工程中的 `Test` 目录）。这是 Unity 的 Bug：Nino 源码必须放在带 `asmdef` 的目录内，为该目录中的类型生成的代码才能正常编译。

如果有多个 `asmdef` 要用 Nino，就把导入的 Nino 文件夹分别复制到这些 `asmdef` 所在的目录。

</Step>
</Steps>

<Callout type="info" title="Unity 报 netstandard 错误">

如果 Unity 报错 `Nino.Core references netstandard, Version=2.1.0.0, Culture=neutral, PublicKeyToken=cc7b13ffcd2ddd51. A roslyn analyzer should reference netstandard version 2.0`，忽略即可，这是 Unity 的 Bug。

</Callout>

<Callout type="idea">

遇到问题时，请先确认已按上述步骤操作，并且 `Nino_Unity` 示例项目能正常运行。如果问题仍然存在，请在 GitHub 上提交 Issue。

</Callout>

#### 代码热更 [#hot-update-code]
- Nino 支持 **HybridCLR** 和 **ILRuntime**。
- 如果要在 Unity 之外单独建一个 C# 工程（而不是 Unity 内的 `asmdef`）来写热更代码，请创建 .NET Core 工程，通过 NuGet 安装 Nino（[见上文](/zh/docs/v2/start#net-project)），再把编译出的 DLL 交给 HybridCLR 或 ILRuntime 使用。
