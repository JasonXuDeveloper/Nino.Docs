## Nino 是什么？ [#what-is-nino]

Nino 是实用的高性能 C# 序列化库，适用于各类 C# 项目，包括但不限于 .NET Core 应用和 Unity、Godot 游戏。给类型加上 `[NinoType]`，源生成器就会在你写代码的同时生成它的序列化代码。运行时调用生成的 `Serializer` 和 `Deserializer` 即可：

```csharp title="Program.cs"
[NinoType]
public class ObjClass
{
    public int Id;
    public string Name { get; set; }
}

byte[] bytes = Serializer.Serialize(obj);
Deserializer.Deserialize(bytes, out ObjClass copy);
```

## 为什么选 Nino v2 [#why-nino-v2]

- **比快更快。** 序列化与反序列化性能远超 JSON、Protobuf、MessagePack 等常规方案，大部分测试结果优于 MemoryPack 等同类库。详见[基准测试](/zh/docs/v2/perf)。
- **简单好用。** 源生成器在你写代码的同时生成序列化与反序列化函数。生成的代码是可以直接阅读的普通 C#，也能在 NativeAOT 等没有 JIT 的平台上运行。
- **功能强大。** 支持基础类型、结构体、类、集合、字典等多种数据类型，也支持多态类型。详见[支持的类型](/zh/docs/v2/types)。
