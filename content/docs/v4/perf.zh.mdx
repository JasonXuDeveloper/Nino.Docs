## 对比对象 [#what-is-compared]

| 对比对象 | 原因 | 测量内容 |
| --- | --- | --- |
| [MemoryPack](https://github.com/Cysharp/MemoryPack) **1.21.4** | .NET 上使用广泛、速度最快的二进制序列化库，和 Nino 一样基于源生成器 | 运行时性能，同一次 BenchmarkDotNet 运行：[序列化](#serialize-to-a-reused-buffer-writer)、[反序列化](#deserialize-new-instances)、[多态对象图](#polymorphism)、[复用实例](#pooling) |
| Nino v3 **3.3.13** | v3 的最后一个版本，也就是你升级之前所用的版本 | 运行时性能，与 v4 在同一台机器上背靠背测量（运行时表格中的 **v4 对比 v3** 列），以及[构建时间](#build-time-and-generated-code) |
| [MessagePack for C#](https://github.com/MessagePack-CSharp/MessagePack-CSharp) | .NET 中最常用的二进制格式 | 运行时性能，同一次运行；列在[全部测量结果](#results)中 |

绝对耗时取决于机器，请比较倍数。功能而非速度方面的对比，参见 [Nino 与 MemoryPack 对比](/zh/docs/v4/vs-memorypack)和 [v3 与 v4 对比](/zh/docs/v4/v3-vs-v4)。

## 测量方法 [#setup]

| | |
| --- | --- |
| CPU | 运行时：Intel Xeon 2.10 GHz，4 核，AVX-512；构建时间：Intel Xeon 2.80 GHz，4 核 |
| 操作系统 | Ubuntu 24.04 |
| 运行时 | .NET 10.0.13（SDK 10.0.402），服务器 GC |
| 测试框架 | BenchmarkDotNet 0.15.2，5 次预热、15 次测量，所有基准测试类在同一次运行中完成 |
| 项目 | [`src/Nino.Benchmark`](https://github.com/JasonXuDeveloper/Nino/tree/main/src/Nino.Benchmark)（运行时），[`src/Nino.GeneratorBenchmark`](https://github.com/JasonXuDeveloper/Nino/tree/main/src/Nino.GeneratorBenchmark)（构建时间） |

- **序列化**测试写入一个只创建一次、每次调用前重置的缓冲区写入器（Nino 用 `NinoArrayBufferWriter`，其他库用 `ArrayBufferWriter<byte>`），因此测的是序列化本身，而不是数组分配。
- **反序列化**测试读取各个库在启动时写好的字节，每次调用都创建新对象。
- **复用**测试反序列化到已经存在的对象中：Nino 通过 `ref` 和 `[NinoPooled]` 对象池，MemoryPack 用它的覆盖模式。
- **v3** 运行的是同一个 `SimpleTest`，但编译时引用的是 NuGet 上的 Nino 3.3.13，在同一台机器上紧挨着 v4 的运行之前和之后各跑一次；v3 的耗时取两次的平均值。

每个基准测试的代码见[基准测试代码](#benchmark-code)。

把一个值或数组写入复用的缓冲区写入器。数据类型：[`SimpleTest`](#simpletest) 和 [`PolymorphicTest`](#polymorphictest)。

<RuntimeTable op="serialize" lang="zh" />

<BenchmarkChart chart="serialize" lang="zh" table={false} />

`SimpleStruct`（`int` + `DateTime`）声明了 `[StructLayout(LayoutKind.Sequential, Pack = 4)]`，所以它占 12 字节，没有填充，所有序列化库都把它当作一整块拷贝。不加 `Pack` 时它占 16 字节，其中 4 字节是填充，Nino 写入时会把填充清零；参见[结构体布局](/zh/docs/v4/performance#struct-layout)。

### 反序列化（新实例） [#deserialize-new-instances]

同样的值，每次调用都读回到新对象中。数据类型：[`SimpleTest`](#simpletest) 和 [`PolymorphicTest`](#polymorphictest)。

<RuntimeTable op="deserialize" lang="zh" />

<BenchmarkChart chart="deserialize" lang="zh" table={false} />

<Callout type="info">

`Vector4[10000]` 每次调用都会在大对象堆上分配一个 160 KB 的数组，所以它测的更多是第 2 代垃圾回收，而不是两个序列化库本身，各次运行之间的波动也较大。拷贝本身在两者中都只是一次 `memcpy`。

## 构建时间与生成代码 [#build-time-and-generated-code]

测试项目是一个合成的程序集：`N` 个抽象根类，每个根类下有 8 层派生类、一个密封叶子类和一个结构体（共 `N × 11` 个类型），成员包括基元类型、字符串、`List<T>`、`Dictionary<int, string>`、对其他 `[NinoType]` 的引用以及私有字段。测试工具在编译过程中运行源生成器（进程内的 Roslyn 4.3），输出程序集，并在修改之后重新运行生成器。耗时取五次运行中后三次的中位数；基线是 v3 3.3.13。

### SimpleTest [#simpletest]

序列化与反序列化：一个包含常见成员类型的类、一个 12 字节的结构体、两者的数组，以及 `Vector4[10000]`。对应[序列化](#serialize-to-a-reused-buffer-writer)和[反序列化](#deserialize-new-instances)两张表。

<Tab value="类型">

```csharp title="SimpleBenchmarkData.cs"
[NinoType]
[MemoryPackable]
[MessagePackObject]
[MemoryPackUnion(0, typeof(SimpleClass))]
[Union(0, typeof(SimpleClass))]
public abstract partial class SimpleClassBase
{
    [Key(0)] public int Id;
    [Key(1)] public bool Tag;
    [Key(2)] public Guid Guid;
    [Key(3)] public DateTime CreateTime;
}

[NinoType]
[MemoryPackable]
[MessagePackObject]
public sealed partial class SimpleClass : SimpleClassBase
{
    [Key(4)] public string Name { get; set; }
    [Key(5)] [NinoUtf8] public string Desc;
    [Key(6)] public int[] Numbers { get; set; }
    [Key(7)] public List<DateTime> Dates { get; set; }
    [Key(8)] public Dictionary<int, string> Map1;
    [Key(9)] public Dictionary<int, int> Map2 { get; set; }
}

[NinoType]
[MemoryPackable]
[MessagePackObject]
[StructLayout(LayoutKind.Sequential, Pack = 4)] // int + DateTime with no padding: 12 bytes
public partial struct SimpleStruct
{
    [Key(0)] public int Id;
    [Key(1)] public DateTime CreateTime;
}
```

```csharp title="SimpleBenchmarkData.cs, SimpleTest.cs"
public static SimpleClass Create()
{
    Random random = new Random();
    return new SimpleClass
    {
        Id = random.Next(),
        Tag = random.Next() % 2 == 0,
        Guid = Guid.NewGuid(),
        CreateTime = DateTime.Now,
        Name = Guid.NewGuid().ToString(),
        Desc = Enumerable.Range(0, 10).Select(_ => Guid.NewGuid().ToString()).Aggregate((a, b) => a + b),
        Numbers = Enumerable.Range(0, 100).Select(_ => random.Next()).ToArray(),
        Dates = Enumerable.Range(0, 10).Select(_ => DateTime.Now.AddSeconds(random.Next())).ToList(),
        Map1 = Enumerable.Range(0, 10).ToDictionary(n => n, n => n.ToString()),
        Map2 = Enumerable.Range(0, 10).ToDictionary(n => n, n => n * 2)
    };
}

{
    Random random = new Random();

    {
        Id = random.Next(),
        CreateTime = DateTime.Now.AddSeconds(random.Next())

}
```

### PolymorphicTest [#polymorphictest]

声明为抽象基类、读回时还原为 21 种子类型之一的值。对应[多态对象图](#polymorphism)中的各行。

<Tabs groupId="bench-code" items={["类型", "数据", "方法"]}>
<Tab value="类型">

```csharp title="PolymorphicBenchmarkData.cs"
[NinoType]
[MemoryPackable]
[MessagePackObject]
[MemoryPackUnion(1, typeof(PolymorphicClass))]
[Union(1, typeof(PolymorphicClass))]
public abstract partial class PolymorphicClassBase
{
    [Key(10)] public int BaseId;

    public abstract void Write();
}

[MemoryPackable]
[MessagePackObject]
[NinoType]
public sealed partial class PolymorphicClass : PolymorphicClassBase, IPolymorphicWriter
{
    [Key(0)] public int Id;
    [Key(1)] public bool Tag;
    [Key(2)] public int[] Numbers;
    [Key(3)] public List<PolymorphicFooBase> Numbers2;
    [Key(4)] public Dictionary<int, PolymorphicFooBase> Map1;
    [Key(5)] public FooD Foo;
    [Key(6)] public HashSet<int> Set;
}

[NinoType]
[MemoryPackable]
[MemoryPackUnion(1, typeof(FooA))]   // ... one [MemoryPackUnion] and one [Union] per subtype,
[Union(1, typeof(FooA))]             // FooA to FooS and FooZ (20 in all)
public abstract partial class PolymorphicFooBase
{
    [Key(0)] public int Id;
}

[NinoType]
[MemoryPackable]
[MessagePackObject]
public partial class FooA : PolymorphicFooBase, IPolymorphicWriter
{
    [Key(1)] public PolymorphicTransform Card;
}

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooB : FooA { [Key(2)] public PolymorphicTransform CardB; }

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooC : FooB { [Key(3)] public PolymorphicTransform CardC; }

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooD : FooC { [Key(4)] public PolymorphicTransform CardD; }

// FooE : FooD, FooF : FooE, FooG : FooF, FooH : FooG add no members (depth 5 to 8).
// FooI, FooJ, ... FooS and FooZ all derive from FooH (depth 9) and add no members.

[MemoryPackable]
[MessagePackObject]
[NinoType]
public partial struct PolymorphicTransform
{
    [Key(0)] public float X;
    [Key(1)] public float Y;
    [Key(2)] public float Z;
}
```

```csharp title="PolymorphicTest.cs"
// Polymorphic class: one PolymorphicClass. Create() fills Numbers (100 ints),
// Map1 (12 Foos: FooA to FooD, three times), Foo (a FooD) and Set (100 ints);
// then 1,000 Foos are added to Numbers2, cycling through the 20 subtypes.
PolymorphicInstance = PolymorphicClass.Create();
var polyClass = (PolymorphicClass)PolymorphicInstance;
for (int i = 0; i < 1000; i++)
{
    switch (i % 20)
    {
        case 0: polyClass.Numbers2.Add(FooA.Create()); break;
        case 1: polyClass.Numbers2.Add(FooB.Create()); break;
        // ... one case per subtype
        case 19: polyClass.Numbers2.Add(FooZ.Create()); break;
    }
}

// Polymorphic Foo[]: 1,000 elements declared as PolymorphicFooBase, the same 20 subtypes in turn
PolymorphicFooArray = new PolymorphicFooBase[1000];

// Polymorphic class array: 100 PolymorphicClass values declared as PolymorphicClassBase,

PolymorphicClassArray = Enumerable.Range(0, 100).Select(_ => /* as above, 50 Foos */).ToArray();
```

### PooledTest [#pooledtest]

把 `SimpleClass` 的成员放进一个 `[NinoPooled]` 类：Nino 从对象池中取实例，对比 MemoryPack 的覆盖模式。对应[复用表](#pooling)中的“池化类”一行。

```csharp title="PooledTest.cs"
[MemoryPackable]
public sealed partial class PooledSimpleClass
{
    public int Id;
    public bool Tag;
    public Guid Guid;
    public DateTime CreateTime;
    public string Name { get; set; }
```

### PooledGraphTest [#pooledgraphtest]

不含字符串的池化对象图，所以稳定运行时可以完全不分配：一个带嵌套池化子对象的节点，以及由 100 个池化叶子组成的列表。对应[复用表](#pooling)中的“池化节点”和“池化叶子”两行。

<Tabs groupId="bench-code" items={["类型", "方法"]}>
<Tab value="类型">

```csharp title="PooledGraphTest.cs"
[NinoType, NinoPooled]
[MemoryPackable]
public sealed partial class PooledLeaf
{
    public int A;
    public float B;
    public List<int> Items;   // 8 ints
```

## 复现 [#reproducing]

克隆 [Nino 仓库](https://github.com/JasonXuDeveloper/Nino)，准备好 .NET 10 SDK 和 Python 3：

```shell
# runtime, as published: v3 3.3.13, then the full v4 suite, then v3 again (about 40 minutes)
benchmarks/run.sh

# runtime, v4 only, a subset
dotnet run -c Release --project src/Nino.Benchmark -- --filter '*SimpleTest*' --iterationCount 15 --warmupCount 5

# build time and generated code (N = 30, 8 derived classes per root)
dotnet run -c Release --project src/Nino.GeneratorBenchmark -- 30 8
```

- `benchmarks/run.sh` 会构建 `benchmarks/v3`（引用 NuGet 上 Nino 3.3.13 的同一个 `SimpleTest`），并在 v4 运行之前和之后各运行一次，抵消 v4 运行期间机器状态的漂移。它会为每个用例和两次 v3 运行分别输出 **v4 对比 v3**。
- 每次发布时，CI 都在同一台运行器上按同样的流程运行，并把结果写进发布说明：Performance Report，以及 **v3 3.3.13 vs v4 (same machine)** 一节。本站的运行时数据取自包含这些数据的最新 v4 版本。
- `benchmarks/members` 把 `SimpleClass` 按成员逐个拆开，分别对比 v3 和 v4，用来找出是哪个成员拖慢了某个用例。参见 [benchmarks README](https://github.com/JasonXuDeveloper/Nino/tree/main/benchmarks)。
