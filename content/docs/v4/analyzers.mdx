Every rule Nino's analyzer reports as you type, on your own code (never in generated files): search by id or words, or filter by severity, code fix or area. A rule with a wrench has a code fix you can apply to a whole document, project or solution.

## Diagnostics

<AnalyzerRules lang="en" />

Each id links to its full explanation in the [diagnostics reference](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md), and `#nino007` after this page's URL links to its row. The NINOGEN ids are reported in the build by [Nino.Codegen and nino-gen](/en/docs/v4/advanced/codegen#diagnostics), which write your types as TypeScript, Go or Rust, not by the analyzer; Nino.TypeScript's `NINOTS001` and `NINOTS002` (up to 4.0.0-rc.7) are now `NINOGEN001` and `NINOGEN002`.

The layout rules, NINO034 to NINO037, report only in a project that has a layout baseline: a file that records the layouts your stored data was written with, created with the refactoring *Create the layout baseline* on any `[NinoType]`, or with `nino-gen layouts` ([Layout Baseline](/en/docs/v4/evolving-data#layout-baseline)).

The analyzer ships with the source generator, in the `Nino.Generator` package and the Unity package, and reports in Visual Studio, Rider and VS Code, and in Unity's console when scripts compile. The code fixes ship in the `Nino.Generator` NuGet package and in the Unity package (`Nino.Generator.CodeFixes.dll`, which Unity lists in the projects it generates for Rider and Visual Studio).

## Changing Severities

You can change severities per project in `.editorconfig`:

```ini title=".editorconfig"
[*.cs]
dotnet_diagnostic.NINO006.severity = none
```

## Suppressed Compiler Warnings

Generated code reads and writes the private members Nino serializes, and the compiler and the IDE cannot always see that access (on .NET 8 and later it goes through `[UnsafeAccessor]`). Nino therefore suppresses these warnings on the private members it serializes: CS0169, CS0414 and CS0649 ("never used / never assigned"), and IDE0044, IDE0051 and IDE0052 ("make readonly", "remove unused member").
