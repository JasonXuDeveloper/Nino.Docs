Nino's analyzer ships with the source generator (in the `Nino.Generator` package and the Unity package). It reports mistakes as you type in Visual Studio, Rider and VS Code, and in Unity's console when scripts compile. The generator itself reports nothing, so every problem shows up on your code rather than in generated files. Diagnostics marked ✅ come with a code fix in the IDE, which you can apply to a whole document, project or solution at once. The code fixes ship in the `Nino.Generator` NuGet package and in the Unity package (`Nino.Generator.CodeFixes.dll`, which Unity lists in the projects it generates for Rider and Visual Studio).

## Diagnostics

The [diagnostics reference](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md) in the Nino repository explains each id in full.

### The Type

| Id | Severity | Problem | What to do | Code fix |
| --- | --- | --- | --- | :---: |
| [NINO001](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino001) | Error | Generated code cannot name the type (it is not `public`/`internal`, or it is `static` or a `ref struct`) | Make the type and its containers `public` or `internal` | ✅ |
| [NINO002](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino002) | Error | The type must be `partial`: it serializes non-public members that generated code reaches through an accessor inside the type (before .NET 8; for generic types before .NET 9, or a member of a generic base with other type arguments), or it is `[NinoPooled]` | Make the type and its containers `partial` | ✅ |
| [NINO003](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino003) | Warning | A subtype of a NinoType with `allowInheritance: false` has no formatter of its own: writing one throws | Add `[NinoType]` to the subtype | ✅ |

### Construction

| Id | Severity | Problem | What to do | Code fix |
| --- | --- | --- | --- | :---: |
| [NINO004](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino004) | Error | No usable constructor | Add a parameterless constructor, one whose parameters match members, or `[NinoConstructor]` |  |
| [NINO005](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino005) | Error | A `[NinoConstructor]` parameter matches no serialized member | Rename the parameter or list the member names in the attribute |  |
| [NINO006](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino006) | Warning | A read-only member is not a constructor parameter, so its value is read and dropped | Add it to the constructor, make it settable, or `[NinoIgnore]` it | ✅ |
| [NINO017](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino017) | Error | Invalid `[NinoFactory]` method | Make it a non-generic `public static` method, callable without arguments, returning the declaring type |  |
| [NINO021](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino021) | Error | `[NinoConstructor]` is `private` or `protected` | Make it `public` or `internal` |  |
| [NINO025](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino025) | Warning | `[NinoFactory]` next to a `[NinoConstructor]` is never called: the type is always re-created through the constructor | Remove `[NinoFactory]` to keep re-creating, or `[NinoConstructor]` to fill factory instances in place | ✅ |

### Members

| Id | Severity | Problem | What to do | Code fix |
| --- | --- | --- | --- | :---: |
| [NINO007](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino007) | Warning | Member type cannot be serialized: the member is skipped; or a generic `[NinoType]` in it is closed over such a type (`Box<Action>`): writing a value throws | `[NinoIgnore]` it, or give it a custom formatter | ✅ |
| [NINO008](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino008) | Error | The `[NinoMemberFormatter]` type is not a struct that implements `INinoFormatter<T>` for exactly the member type | Fix the formatter's type |  |
| [NINO009](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino009) | Error | Non-public `[NinoMember]` in a type without `includeNonPublicMembers` | Remove `[NinoMember]` or set `includeNonPublicMembers: true` | ✅ |
| [NINO010](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino010) | Warning | Redundant `[NinoMember]` with `autoCollect: true` | Remove it | ✅ |
| [NINO011](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino011) | Warning | Redundant `[NinoIgnore]` with `autoCollect: false` | Remove it | ✅ |
| [NINO012](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino012) | Error | Member has both `[NinoMember]` and `[NinoIgnore]` | Remove one or both | ✅ |
| [NINO013](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino013) | Error | Duplicate `[NinoMember]` index | Use the next free index | ✅ |
| [NINO022](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino022) | Warning | A non-public base member hidden with `new` cannot be reached (it can through `[UnsafeAccessor]`: .NET 8+, generic types .NET 9+); it is skipped | Rename one of the members, or make it public |  |
| [NINO023](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino023) | Error | A struct serializes no members: it would be zero bytes, and a collection of it could not be read back | Serialize a member, or make the struct `VersionTolerant` or `Keyed` |  |

### Formats and References

| Id | Severity | Problem | What to do | Code fix |
| --- | --- | --- | --- | :---: |
| [NINO014](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino014) | Error | Two keyed members (or a member's `[NinoFormerName]`) hash to the same key | Rename one of them, or drop the former name |  |
| [NINO024](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino024) | Warning | `[NinoFormerName]` has no effect outside a keyed type: positional and version-tolerant types write no member names | Remove it, or give the type `format: NinoFormat.Keyed` | ✅ |
| [NINO026](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino026) | Error | More than one `[NinoFormerName]` on a type: its type id comes from a single earlier name | Keep only the name the data you still read was written under |  |
| [NINO027](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino027) | Warning | `[NinoFormerName]` on a generic type written with a type id: every instantiation takes the same id | Remove the former name, or keep former names on non-generic types |  |
| [NINO015](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino015) | Warning | `trackReferences` on a struct is ignored | Remove `trackReferences` | ✅ |
| [NINO016](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino016) | Error | `trackReferences` on a type re-created from its constructor (e.g. a positional record) | Make the members assignable |  |

A member's `[NinoFormerName]`s are keys too, so a former name that equals another member's name (or has the same hash) triggers NINO014. A former name equal to the member's own name is ignored. See [Renaming Keyed Members](/en/docs/v4/evolving-data#renaming-keyed-members).

### Formatter Registrations

| Id | Severity | Problem | What to do | Code fix |
| --- | --- | --- | --- | :---: |
| [NINO020](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md#nino020) | Error | Invalid `[assembly: NinoFormatter]` registration; it is ignored | Register a struct, not nested in a generic type, that implements `INinoFormatter<P>` once: a generic one as its open definition (`typeof(F<,>)`), with type parameters that can be inferred, a non-generic one as itself (`typeof(F)`) |  |

### Code Generation for Other Languages [#code-generation]

[Nino.Codegen and nino-gen](/en/docs/v4/advanced/codegen#diagnostics), which write your types as TypeScript, Go or Rust, report their own ids in the build, outside the analyzer:

| Id | Severity | Problem | What to do |
| --- | --- | --- | --- |
| NINOGEN001 | Error | Invalid arguments or `<NinoCodegen>` metadata (an unknown option, one given twice or of another language, a value it does not take), or an assembly it cannot read | Fix the option or the item |
| NINOGEN002 | Warning | A type is left out because the language cannot express it | See [What Is Not Generated](/en/docs/v4/advanced/codegen#not-generated) |
| NINOGEN003 | Warning | The project sets Nino.TypeScript's `NinoTypeScript*` properties | Declare a `<NinoCodegen>` item instead ([migration](/en/docs/v4/advanced/codegen#from-ninotypescript)) |
| NINOGEN004 | Warning | The project references Nino.Codegen but declares no `<NinoCodegen>` item | Add one, or set `NinoCodegenEnabled` to `false` |

Nino.TypeScript's `NINOTS001` and `NINOTS002` (up to 4.0.0-rc.7) are now `NINOGEN001` and `NINOGEN002`.

## Changing Severities

You can change severities per project in `.editorconfig`:

```ini title=".editorconfig"
[*.cs]
dotnet_diagnostic.NINO006.severity = none
```

## Suppressed Compiler Warnings

Generated code reads and writes the private members Nino serializes, and the compiler and the IDE cannot always see that access (on .NET 8 and later it goes through `[UnsafeAccessor]`). Nino therefore suppresses these warnings on the private members it serializes: CS0169, CS0414 and CS0649 ("never used / never assigned"), and IDE0044, IDE0051 and IDE0052 ("make readonly", "remove unused member").
