Nino 反序列化每个类型时，都需要知道如何创建它的实例，依次尝试：

1. 标记了 `[NinoConstructor]` 的构造函数或静态工厂方法（如果有）。
2. 否则，选用可访问（`public` 或 `internal`）的构造函数中参数最多、且每个参数都能按名称（不区分大小写）对应到某个序列化成员的那个。对记录来说通常就是主构造函数；无参构造函数视为零个参数，同样满足条件。
3. 结构体最后退回到 `new T()`。

`[NinoConstructor]` 的参数是依次传给构造函数的成员名称。不写名称时，按参数名匹配成员：

<Tabs items={["构造函数", "工厂方法", "主构造函数", "结构体"]}>

<Tab value="构造函数">

```csharp
[NinoType]
public record SimpleRecord
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    public SimpleRecord()
    {
        Id = 0;
        Name = string.Empty;
        CreateTime = DateTime.MinValue;
    }

    [NinoConstructor(nameof(Id), nameof(Name))] // [!code highlight]
    public SimpleRecord(int id, string name)
    {
        Id = id;
        Name = name;
        CreateTime = DateTime.Now;
    }
}
```

</Tab>
<Tab value="工厂方法">

```csharp
[NinoType]
public class Move
{
    public ushort ClientX;
    public ushort ClientY;

    private Move() { }

    [NinoConstructor(nameof(ClientX), nameof(ClientY))] // [!code highlight]
    public static Move Create(ushort clientX, ushort clientY)
    {
        return new Move { ClientX = clientX, ClientY = clientY };
    }
}
```

</Tab>
<Tab value="主构造函数">

```csharp
[NinoType]
public record SimpleRecord2(int Id, string Name, DateTime CreateTime); // [!code highlight]
```

</Tab>
<Tab value="结构体">

```csharp
[NinoType]
public struct SimpleStruct
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    // used instead of the implicit parameterless constructor
    [NinoConstructor(nameof(Id), nameof(Name), nameof(CreateTime))] // [!code highlight]
    public SimpleStruct(int a, string b, DateTime c)
    {
        Id = a;
        Name = b;
        CreateTime = c;
    }
}
```

</Tab>
</Tabs>

## 规则 [#rules]
- 标记了 `[NinoConstructor]` 的构造函数或工厂方法必须是 `public` 或 `internal`（NINO021）。
- `[NinoConstructor]` 中的每个名称（不写名称时则是每个参数）都必须对应一个序列化成员（NINO005）。
- 找不到可用的构造函数时，报告 NINO004。
- 通过构造函数重新创建的类型，如果某个只读成员不是构造函数参数，它的值会被读出后丢弃（NINO006）。请把它加入构造函数、改为可写，或用 `[NinoIgnore]` 忽略。
- C# 11 的 `required` 成员：如果有匹配的 `[SetsRequiredMembers]` 构造函数，就使用它；否则生成代码会用对象初始化器设置 required 成员，因此每个 required 成员都必须参与序列化，并且能被生成代码赋值（`public` 或 `internal`）。

## 构造函数还是工厂方法？ [#constructor-or-factory]

Nino 提供两种介入实例创建的方式，用途不同：

| | `[NinoConstructor]` | [`[NinoFactory]`](/zh/docs/v4/pooling#creating-instances-with-ninofactory) |
| --- | --- | --- |
| 标记在 | 构造函数或静态工厂方法上 | 可无参调用的公共静态方法上 |
| 接收 | 所列成员反序列化后的值 | 无 |
| 适合 | 构造不可变类型、校验参数、计算派生状态 | 从你自己的对象池中取实例 |
| 调用之后 | 不是参数的成员会被逐个赋值 | 所有成员都原地填充 |

## 重新创建的类型 [#re-created-types]

如果类型的成员在构造之后无法再赋值（构造函数参数、`init` 属性、只读属性或 `readonly` 字段），那么每次反序列化都会**重新创建**它，即使是 [复用反序列化](/zh/docs/v4/pooling)也不例外，旧实例会交给回收器。这类类型不能使用 [`trackReferences`](/zh/docs/v4/reference-tracking)（NINO016）或 [`[NinoPooled]`](/zh/docs/v4/pooling#ninopooled)（NINO018）。需要这两项功能时，请让成员可写。
