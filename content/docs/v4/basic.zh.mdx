`NinoSerializer` 和 `NinoDeserializer`（命名空间 `Nino.Core`）就是全部的运行时 API。两者都是静态类，并且**线程安全**：可以在任意多个线程上同时调用，无需加锁。每次调用用到的临时状态（暂存缓冲区、引用表）按线程保存，热路径上不会写共享内存。

## 序列化 [#serializing]

```csharp
// Into a new byte array
byte[] NinoSerializer.Serialize<T>(T value);

// Into any IBufferWriter<byte>
void NinoSerializer.Serialize<T>(T value, IBufferWriter<byte> bufferWriter);

// With an existing Writer (several values in one buffer, custom formatters)
void NinoSerializer.Serialize<T>(T value, ref Writer writer);

// Boxed values, when the type is only known at run time
byte[] NinoSerializer.Serialize(object value);    // as value.GetType(); value must not be null
void NinoSerializer.SerializeBoxed(object value, IBufferWriter<byte> bufferWriter, Type type);
void NinoSerializer.SerializeBoxed(object value, ref Writer writer, Type type);
```

`T` 可以是任何[受支持的类型](/zh/docs/v4/types)：`[NinoType]`、基元类型、字符串、集合等。

```csharp
byte[] bytes = NinoSerializer.Serialize(player);
```

### 复用缓冲区 [#reusing-a-buffer]

`Serialize<T>(value)` 每次都会为结果分配一个 `byte[]`。想做到零分配，就序列化到一个长期持有的缓冲区里。

`NinoArrayBufferWriter` 是 Nino 自带的 `IBufferWriter<byte>`，底层数组租自 `ArrayPool<byte>.Shared`，Nino 会**直接写入**其中。其他 `IBufferWriter<byte>`（.NET 的 `ArrayBufferWriter<byte>`、`PipeWriter`、包装 `Stream` 的写入器）则会在最后多一次拷贝。

```csharp
var buffer = new NinoArrayBufferWriter();      // or new NinoArrayBufferWriter(initialCapacity)

NinoSerializer.Serialize(player, buffer);
ReadOnlySpan<byte> bytes = buffer.WrittenSpan; // also WrittenMemory, WrittenCount, ToArray()
// ... send or store the bytes ...

buffer.ResetWrittenCount();                    // reuse the same array
NinoSerializer.Serialize(player, buffer);      // no allocation this time
```

<Callout type="warn">

`NinoArrayBufferWriter` **不是**线程安全的：每个线程、每个连接或每次操作各用一个。不再使用时调用 `Dispose()`，把数组还给池。

</Callout>

### 一个缓冲区写多个值 [#several-values-in-one-buffer]

`Writer` 是写入 `NinoArrayBufferWriter` 的 `ref struct`。需要连续写入多个值，或者在[自定义格式化器](/zh/docs/v4/custom-formatters)中写数据时使用它：

```csharp
var buffer = new NinoArrayBufferWriter();
var writer = new Writer(buffer);
NinoSerializer.Serialize(header, ref writer);
NinoSerializer.Serialize(body, ref writer);
writer.Flush();             // commits the bytes to buffer.WrittenCount (Dispose() does the same)
writer.ReleaseReferences(); // ends reference tracking, see below
```

<Callout type="info">

顶层重载会把[引用追踪](/zh/docs/v4/reference-tracking)的范围限定在单次调用内。自己创建 `Writer`（或 `Reader`）时，通过它写入的所有内容共用一张引用表，直到调用 `ReleaseReferences()` 为止。请在一条完整消息结束时调用它；如果没有写入任何启用追踪的类型，这个调用没有开销。

</Callout>

## 反序列化 [#deserializing]

```csharp
// A new value
T NinoDeserializer.Deserialize<T>(ReadOnlySpan<byte> data);

// Into an existing value, reusing its instances
void NinoDeserializer.Deserialize<T>(ReadOnlySpan<byte> data, ref T value);
void NinoDeserializer.DeserializeRef<T>(ref T value, ReadOnlySpan<byte> data); // same as above

// With an existing Reader
T NinoDeserializer.Deserialize<T>(ref Reader reader);
void NinoDeserializer.Deserialize<T>(ref T value, ref Reader reader);
void NinoDeserializer.DeserializeRef<T>(ref T value, ref Reader reader);        // same as above

// Boxed values, when the type is only known at run time
object NinoDeserializer.Deserialize(ReadOnlySpan<byte> data, Type type);
void NinoDeserializer.Deserialize(ReadOnlySpan<byte> data, Type type, ref object value);
void NinoDeserializer.DeserializeBoxed(ref object value, ref Reader reader, Type type);
```

数据类型是 `ReadOnlySpan<byte>`：`byte[]`、`ArraySegment<byte>`、`Span<byte>`、`Memory<byte>.Span`，或者现有缓冲区的任意切片都可以直接传入，无需拷贝。

```csharp
Player player = NinoDeserializer.Deserialize<Player>(bytes);
Player fromSlice = NinoDeserializer.Deserialize<Player>(rented.AsSpan(0, received));
```

### 反序列化到已有值 [#into-an-existing-value]

用 `ref` 传入已有的值，Nino 会原地填充，尽可能复用这个实例以及其中的嵌套对象、列表、数组和字典。传入 `null`（或 `default`）则创建新值。

```csharp
Player player = null;
foreach (var message in messages)
{
    NinoDeserializer.Deserialize(message, ref player); // the first call creates player, later calls reuse it
    Handle(player);
}
```

过程中被丢弃的实例（数据中为 `null`、列表变短、字典少了某个键、多态类型变了）可以归还到对象池。Nino 没有 `out` 重载：要新实例就用返回值，要复用就用 `ref`。详见 [ref 反序列化与对象池](/zh/docs/v4/pooling)。

### 从一个缓冲区读多个值 [#several-values-from-one-buffer]

连续写入的多个值，用 `Reader` 按相同顺序读回：

```csharp
var reader = new Reader(buffer.WrittenSpan);
var header = NinoDeserializer.Deserialize<Header>(ref reader);
var body = NinoDeserializer.Deserialize<Body>(ref reader);
reader.ReleaseReferences();
```

### 多段数据 [#multi-segment-data]

Nino 没有 `ReadOnlySequence<byte>` 重载。`System.IO.Pipelines` 给出的序列通常只有一段，直接传入即可；如果有多段，先拷贝到一块连续内存：

```csharp
static Player Read(ReadOnlySequence<byte> data)
{
    if (data.IsSingleSegment)
        return NinoDeserializer.Deserialize<Player>(data.First.Span);

    int length = (int)data.Length;
    byte[] rented = ArrayPool<byte>.Shared.Rent(length);
    try
    {
        data.CopyTo(rented);
        return NinoDeserializer.Deserialize<Player>(rented.AsSpan(0, length));
    }
    finally
    {
        ArrayPool<byte>.Shared.Return(rented);
    }
}
```

## 运行时类型 [#runtime-types]

类型只有在运行时才知道时（插件系统、编辑器工具、以 `Type` 为键的消息表），使用装箱重载。序列化和反序列化必须用**同一个**类型：

```csharp
object value = GetComponentData();
byte[] bytes = NinoSerializer.Serialize(value);                    // written as value.GetType()
object copy = NinoDeserializer.Deserialize(bytes, value.GetType());

// a value declared as a base type: write and read it as that type, so the subtype is preserved
NinoSerializer.SerializeBoxed(shape, buffer, typeof(Shape));
object read = NinoDeserializer.Deserialize(buffer.WrittenSpan, typeof(Shape));
```

装箱重载按 `Type` 查找格式化器（首次调用后缓存），值类型会被装箱。编译期已知类型时，请优先使用泛型重载。

## 无效数据 [#invalid-data]

从数据中读出的每个长度，都会先与剩余字节数比对，再分配内存，因此畸形或恶意数据无法诱发巨量分配。无效数据会抛出 `InvalidOperationException`，消息以 `Nino:` 开头，例如数据被截断（"unexpected end of data"）、长度不可能成立、类型 ID 未知，或类型 ID 不是声明类型的子类型。读取永远不会越过 span 的末尾。

但如果数据是按**另一个**布局兼容的类型写出的，Nino 无法察觉：字节中不带 schema。请自行为数据加上版本信息（参见[数据演进](/zh/docs/v4/evolving-data)和[存档文件头](/zh/docs/v4/advanced/persistence#add-a-file-header)）。
