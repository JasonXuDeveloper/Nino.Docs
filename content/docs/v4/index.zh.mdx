Nino 把你的 C# 类型转换为紧凑的字节，并能再转换回来。Roslyn 源生成器会在编译期为每个标记了 `[NinoType]` 的类型生成序列化代码，因此序列化过程不涉及反射、运行时代码生成，也不需要注册步骤；它在 .NET、Unity（Mono 与 IL2CPP）以及 HybridCLR 上的表现完全一致。

<Stats lang="zh" />

```csharp
using Nino.Core;

[NinoType]
public class GameData
{
    public int Score;
    public string PlayerName;
    public List<Item> Items;
}

byte[] bytes = NinoSerializer.Serialize(data);
GameData copy = NinoDeserializer.Deserialize<GameData>(bytes);
```

## Nino 能处理什么

- **你使用的类型**：基础类型、枚举、结构体、类、记录、泛型、可空类型、元组、BCL 集合、你自己的集合、不可变集合，以及 `Vector3` 等 Unity 类型。参见[支持的类型](/zh/docs/v4/types)和[定义类型](/zh/docs/v4/defining-types)。
- **对象模型**：通过基类和接口实现的[多态](/zh/docs/v4/polymorphism)、[自定义构造函数](/zh/docs/v4/constructors)、私有成员，以及[共享引用与循环引用](/zh/docs/v4/reference-tracking)。
- **会变化的数据**：[版本兼容](/zh/docs/v4/evolving-data#version-tolerance)、[键控成员](/zh/docs/v4/evolving-data#keyed-members)以及[重命名的类型](/zh/docs/v4/defining-types#former-name)。
- **热路径**：缓冲区复用、零分配的[反序列化到已有实例与对象池](/zh/docs/v4/pooling)，以及去掉最后一层间接调用的[拦截器](/zh/docs/v4/performance#interceptors)。
- **在编译期发现错误**：[分析器](/zh/docs/v4/analyzers)会在你输入时报告问题，大多附带代码修复。
