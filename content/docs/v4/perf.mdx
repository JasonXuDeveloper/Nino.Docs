This page has every benchmark number the documentation quotes, the code that produces them, and how to run it yourself. Other pages summarize these results and link here.

## What Is Compared [#what-is-compared]

| Against | Why | What is measured |
| --- | --- | --- |
| [MemoryPack](https://github.com/Cysharp/MemoryPack) **1.21.4** | The fastest widely used binary serializer for .NET, and source-generated like Nino | Runtime, in the same BenchmarkDotNet run: [serialize](#serialize-to-a-reused-buffer-writer), [deserialize](#deserialize-new-instances), [polymorphic graphs](#polymorphism), [reusing instances](#pooling) |
| Nino v3 **3.3.13** | The last v3 release, the version you would upgrade from | Runtime, back to back with v4 on the same machine (the **v4 vs v3** column of the runtime tables), and [build time](#build-time-and-generated-code) |
| [MessagePack for C#](https://github.com/MessagePack-CSharp/MessagePack-CSharp) | The most common binary format in .NET | Runtime, in the same run; listed in [All Measurements](#results) |

Absolute times depend on the machine; compare the ratios. For features rather than speed, see [Nino vs MemoryPack](/en/docs/v4/vs-memorypack) and [v3 vs v4](/en/docs/v4/v3-vs-v4).

## How It Is Measured [#setup]

| | |
| --- | --- |
| CPU | Runtime: Intel Xeon 2.10 GHz, 4 cores, AVX-512; build time: Intel Xeon 2.80 GHz, 4 cores |
| OS | Ubuntu 24.04 |
| Runtime | .NET 10.0.13 (SDK 10.0.402), server GC |
| Harness | BenchmarkDotNet 0.15.2, 5 warm-up and 15 measured iterations, every benchmark class in one run |
| Projects | [`src/Nino.Benchmark`](https://github.com/JasonXuDeveloper/Nino/tree/main/src/Nino.Benchmark) (runtime), [`src/Nino.GeneratorBenchmark`](https://github.com/JasonXuDeveloper/Nino/tree/main/src/Nino.GeneratorBenchmark) (build time) |

- **Serialize** benchmarks write into a buffer writer that is created once and reset before each call (`NinoArrayBufferWriter` for Nino, `ArrayBufferWriter<byte>` for the others), so they measure the serializer, not array allocation.
- **Deserialize** benchmarks read bytes that each serializer wrote at startup, and create new objects on every call.
- **Reuse** benchmarks deserialize into objects that already exist: Nino by `ref` and from `[NinoPooled]` pools, MemoryPack with its overwrite mode.
- **v3** runs the same `SimpleTest` built against Nino 3.3.13 from NuGet, directly before and after the v4 run on the same machine; its time is the mean of the two runs.

The code of every benchmark is in [Benchmark Code](#benchmark-code).

## Build Time and Generated Code [#build-time-and-generated-code]

The test project is a synthetic assembly of `N` abstract root classes, each with a chain of 8 derived classes, a sealed leaf and a struct (`N × 11` types), with primitives, strings, `List<T>`, `Dictionary<int, string>`, references to other `[NinoType]`s and private fields. The harness runs the generator on the compilation (Roslyn 4.3 in-process), emits the assembly, and re-runs the generator after an edit. Times are the median of the last three of five runs; the baseline is v3 3.3.13.

<BenchmarkChart chart="compile" lang="en" table={false} />

public static SimpleClass Create()
{
    Random random = new Random();

        Guid = Guid.NewGuid(),
        CreateTime = DateTime.Now,
        Name = Guid.NewGuid().ToString(),
        Desc = Enumerable.Range(0, 10).Select(_ => Guid.NewGuid().ToString()).Aggregate((a, b) => a + b),
        Numbers = Enumerable.Range(0, 100).Select(_ => random.Next()).ToArray(),
        Dates = Enumerable.Range(0, 10).Select(_ => DateTime.Now.AddSeconds(random.Next())).ToList(),
        Map1 = Enumerable.Range(0, 10).ToDictionary(n => n, n => n.ToString()),
        Map2 = Enumerable.Range(0, 10).ToDictionary(n => n, n => n * 2)
    };
}

public static SimpleStruct Create()
{
    Random random = new Random();

    {
        Id = random.Next(),
        CreateTime = DateTime.Now.AddSeconds(random.Next())

// SimpleTest's static constructor

### PolymorphicTest [#polymorphictest]

Values declared as an abstract base and read back as one of 21 subtypes. Used by the [polymorphic graphs](#polymorphism) rows.

<Tabs groupId="bench-code" items={["Types", "Data", "Methods"]}>
<Tab value="Types">

```csharp title="PolymorphicBenchmarkData.cs"
[NinoType]
[MemoryPackable]
[MessagePackObject]
[MemoryPackUnion(1, typeof(PolymorphicClass))]
[Union(1, typeof(PolymorphicClass))]
public abstract partial class PolymorphicClassBase
{
    [Key(10)] public int BaseId;

    public abstract void Write();
}

[MemoryPackable]
[MessagePackObject]
[NinoType]
public sealed partial class PolymorphicClass : PolymorphicClassBase, IPolymorphicWriter
{
    [Key(0)] public int Id;
    [Key(1)] public bool Tag;
    [Key(2)] public int[] Numbers;
    [Key(3)] public List<PolymorphicFooBase> Numbers2;
    [Key(4)] public Dictionary<int, PolymorphicFooBase> Map1;
    [Key(5)] public FooD Foo;
    [Key(6)] public HashSet<int> Set;
}

[NinoType]
[MemoryPackable]
[MemoryPackUnion(1, typeof(FooA))]   // ... one [MemoryPackUnion] and one [Union] per subtype,
[Union(1, typeof(FooA))]             // FooA to FooS and FooZ (20 in all)
public abstract partial class PolymorphicFooBase
{
    [Key(0)] public int Id;
}

[NinoType]
[MemoryPackable]
[MessagePackObject]
public partial class FooA : PolymorphicFooBase, IPolymorphicWriter
{
    [Key(1)] public PolymorphicTransform Card;
}

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooB : FooA { [Key(2)] public PolymorphicTransform CardB; }

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooC : FooB { [Key(3)] public PolymorphicTransform CardC; }

[NinoType] [MemoryPackable] [MessagePackObject]
public partial class FooD : FooC { [Key(4)] public PolymorphicTransform CardD; }

// FooE : FooD, FooF : FooE, FooG : FooF, FooH : FooG add no members (depth 5 to 8).
// FooI, FooJ, ... FooS and FooZ all derive from FooH (depth 9) and add no members.

[MemoryPackable]
[MessagePackObject]
[NinoType]
public partial struct PolymorphicTransform
{
    [Key(0)] public float X;
    [Key(1)] public float Y;
    [Key(2)] public float Z;
}
```

</Tab>
<Tab value="Data">

```csharp title="PolymorphicTest.cs"
// Polymorphic class: one PolymorphicClass. Create() fills Numbers (100 ints),
// Map1 (12 Foos: FooA to FooD, three times), Foo (a FooD) and Set (100 ints);
// then 1,000 Foos are added to Numbers2, cycling through the 20 subtypes.
PolymorphicInstance = PolymorphicClass.Create();
var polyClass = (PolymorphicClass)PolymorphicInstance;
for (int i = 0; i < 1000; i++)
{
    switch (i % 20)
    {
        case 0: polyClass.Numbers2.Add(FooA.Create()); break;
        case 1: polyClass.Numbers2.Add(FooB.Create()); break;
        // ... one case per subtype
        case 19: polyClass.Numbers2.Add(FooZ.Create()); break;
    }
}

// Polymorphic Foo[]: 1,000 elements declared as PolymorphicFooBase, the same 20 subtypes in turn
PolymorphicFooArray = new PolymorphicFooBase[1000];

// Polymorphic class array: 100 PolymorphicClass values declared as PolymorphicClassBase,
// each with 50 Foos in Numbers2
PolymorphicClassArray = Enumerable.Range(0, 100).Select(_ => /* as above, 50 Foos */).ToArray();
```

</Tab>

## Reproducing [#reproducing]

From a clone of the [Nino repository](https://github.com/JasonXuDeveloper/Nino), with the .NET 10 SDK and Python 3:

```shell
# runtime, as published: v3 3.3.13, then the full v4 suite, then v3 again (about 40 minutes)
benchmarks/run.sh

# runtime, v4 only, a subset
dotnet run -c Release --project src/Nino.Benchmark -- --filter '*SimpleTest*' --iterationCount 15 --warmupCount 5

# build time and generated code (N = 30, 8 derived classes per root)
dotnet run -c Release --project src/Nino.GeneratorBenchmark -- 30 8
```

- `benchmarks/run.sh` builds `benchmarks/v3` (the same `SimpleTest` against Nino 3.3.13 from NuGet) and runs it before and after v4, so drift of the machine during the v4 run averages out. It prints **v4 vs v3** for each case and both v3 runs.
- Every release runs the same protocol in CI, on one runner, and publishes the result in the release notes: the Performance Report, and a **v3 3.3.13 vs v4 (same machine)** section. This site takes its runtime numbers from the newest v4 release that has them.
- `benchmarks/members` takes `SimpleClass` apart member by member, against v3 and v4, to find which member makes a case slower. See the [benchmarks README](https://github.com/JasonXuDeveloper/Nino/tree/main/benchmarks).
