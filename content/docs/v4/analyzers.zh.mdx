这里列出 Nino 分析器在你写代码时报告的全部规则，只报在你自己的代码上，从不报在生成的文件里。可以按编号或关键词搜索，也可以按级别、有无代码修复或领域筛选。带扳手图标的规则有代码修复，可以一次应用到整个文档、项目或解决方案。

## 诊断列表 [#diagnostics]

<AnalyzerRules lang="zh" />

每个编号都链接到[诊断参考](https://github.com/JasonXuDeveloper/Nino/blob/main/docs/diagnostics.md)里的完整说明；在本页地址后加 `#nino007`，就能直接定位到那一行。NINOGEN 开头的编号不是分析器报的，而是 [Nino.Codegen 和 nino-gen](/zh/docs/v4/advanced/codegen#diagnostics) 在构建时报的，它们把你的类型写成 TypeScript、Go 或 Rust。Nino.TypeScript 的 `NINOTS001` 和 `NINOTS002`（到 4.0.0-rc.7 为止）现已改为 `NINOGEN001` 和 `NINOGEN002`。

布局规则 NINO034 到 NINO037 只在有布局基线的项目里报告。布局基线是一个文件，记下已存数据写出时的布局；在任意 `[NinoType]` 上用重构“创建布局基线”（*Create the layout baseline*）生成，或者用 `nino-gen layouts` 生成（[布局基线](/zh/docs/v4/evolving-data#layout-baseline)）。

分析器随源生成器一起发布（`Nino.Generator` 包和 Unity 包里都有），在 Visual Studio、Rider 和 VS Code 里实时显示，Unity 编译脚本时显示在控制台。代码修复同样在 `Nino.Generator` NuGet 包和 Unity 包里（即 `Nino.Generator.CodeFixes.dll`，Unity 为 Rider 和 Visual Studio 生成项目时会把它列进去）。

## 修改严重级别 [#changing-severities]

可以在 `.editorconfig` 中按项目修改严重级别：

```ini title=".editorconfig"
[*.cs]
dotnet_diagnostic.NINO006.severity = none
```

## 屏蔽的编译器警告 [#suppressed-compiler-warnings]

生成代码会读写 Nino 要序列化的私有成员，而编译器和 IDE 不一定看得出这种访问（在 .NET 8 及以上，它走的是 `[UnsafeAccessor]`）。所以 Nino 会在它序列化的私有成员上屏蔽这些警告：CS0169、CS0414 和 CS0649（“从未使用 / 从未赋值”），以及 IDE0044、IDE0051 和 IDE0052（“设为只读”“删除未使用的成员”）。
