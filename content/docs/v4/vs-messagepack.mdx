[MessagePack for C#](https://github.com/MessagePack-CSharp/MessagePack-CSharp) (MessagePack-CSharp) is one of the most widely used binary serializers in .NET. It writes [MessagePack](https://msgpack.org), a format that libraries in many languages read. This page compares Nino v4 with MessagePack for C# **3.1.12**, the version Nino's benchmark runs, using MessagePack's README and source for its features and Nino's source for Nino's; behavior marked "tested" was checked with 3.1.12 in a test program. A MessagePack 4.0 preview has been announced; this page describes 3.x. Where we could not verify a feature, it is left out. How both compare with MemoryPack, protobuf and System.Text.Json is on [Choosing a Serializer](/en/docs/v4/compare).

## Two Formats [#formats]

The deepest difference is what the bytes are. MessagePack is a self-describing format: every value carries a type tag, so any MessagePack reader can parse it without your types. Nino's bytes carry no tags: your C# types say how to read them, in .NET and in the Go, Rust and TypeScript code [nino-gen](/en/docs/v4/advanced/codegen) generates from them.

| | Nino v4 | MessagePack for C# |
| --- | --- | --- |
| A value | its bytes only | a type tag (integer, string, array, map...) and its bytes |
| An object | its members one after another; with [`NinoFormat.Keyed`](/en/docs/v4/evolving-data#keyed-members), a key and a length per member (8 bytes) | an array of its members (integer `[Key]`s) or a map from names to members (string keys) |
| A subtype | a 4-byte type id, a hash of the type's name | a two-element array: the union key, then the object |
| Integers | at their full width (an `int` is 4 bytes) | in the fewest bytes that hold the value (0 to 127 in one byte) |
| Strings | one byte a char when every char is at most U+00FF, else UTF-16; UTF-8 with [`[NinoUtf8]`](/en/docs/v4/defining-types#string-encoding) | UTF-8 |
| `Guid`, `DateTime` | 16 bytes; ticks and kind | a 36-character string; a MessagePack timestamp, in UTC (native resolvers change both) |

## Performance [#performance]

Measured with BenchmarkDotNet in the same run as Nino, on the same values and the same types, MessagePack through the API its documentation recommends for speed with the formatters its source generator writes ([setup](/en/docs/v4/benchmarks#messagepack-and-protobuf-net)). <IfWorkloads>On the [real workloads](/en/docs/v4/benchmarks#workloads) where Nino leads, it serializes <BenchValue k="workloads.messagepack.serialize" /> faster and deserializes <BenchValue k="workloads.messagepack.deserialize" /> faster.</IfWorkloads><IfWorkloads not>In the classes and polymorphic types where Nino leads, it serializes <BenchValue k="messagepack.serialize" /> faster and deserializes <BenchValue k="messagepack.deserialize" /> faster.</IfWorkloads> Cases MessagePack cannot express with the same data (reference tracking, deserializing into existing objects, generic bases) are left out.

Payload sizes differ by format, not by effort: MessagePack writes small integers in fewer bytes and a `Guid` as a string, Nino writes integers at their full width and a `Guid` as 16 bytes.

## Untrusted Input [#untrusted-input]

MessagePack's README warns that, "depending on the settings used during deserialization, untrusted data may be able to execute arbitrary code or cause a denial of service attack", and asks you to opt into a safer mode for such data: `MessagePackSerializerOptions.Standard.WithSecurity(MessagePackSecurity.UntrustedData)`, passed to each call or set as `MessagePackSerializer.DefaultOptions`. The default options use `MessagePackSecurity.TrustedData`. The README calls the safer mode a hardening "against some common attacks", "no fully secure solution in itself", and says to avoid the Typeless API for untrusted data, since it writes type names into the data ([MessagePack README, Security](https://github.com/MessagePack-CSharp/MessagePack-CSharp#security)).

Nino reads untrusted data in its default mode; [`NinoSettings.Untrusted`](/en/docs/v4/security#untrusted-mode) adds the checks that cost time on every read.

## Where MessagePack Is Ahead [#where-messagepack-is-ahead]

MessagePack does these things and Nino v4 does not:

- **Any language reads the data.** MessagePack is a standard format with libraries in many languages, and its data can be read without your types: as JSON with `ConvertToJson`, or as `Deserialize<dynamic>`. Nino's data is read through your C# types, or through the Go, Rust and TypeScript code generated from them.
- **No attributes needed.** `ContractlessStandardResolver` writes any public type by member name, much like a JSON serializer.
- **Smaller integers.** Small numbers take fewer bytes than their full width.
- **`System.Type` values and typeless data**, for trusted data.
- **Options per call**: `MessagePackSerializerOptions` picks the resolver, the security mode and the compression per call.
- **Compression built in**: LZ4 is an option of each call.
- **Frameworks built on it**: MagicOnion (code-first gRPC) and StreamJsonRpc.

The workaround for what Nino leaves out is on [Limitations](/en/docs/v4/compare#limitations). Which to choose for which job: [Which to Choose](/en/docs/v4/compare#which-to-choose).

## Switching from MessagePack [#switching-from-messagepack]

| MessagePack | Nino |
| --- | --- |
| `[MessagePackObject]` | `[NinoType]` |
| `[Key(0)]`, `[Key(1)]`... on each member | nothing: public members in declaration order; or `[NinoType(false)]` with `[NinoMember(n)]` on the members to write ([Choosing Members Explicitly](/en/docs/v4/defining-types#choosing-members-explicitly)) |
| `[Key("name")]`, `keyAsPropertyName: true` | `[NinoType(format: NinoFormat.Keyed)]`: members by name, renamed with `[NinoFormerName]` ([Keyed Members](/en/docs/v4/evolving-data#keyed-members)) |
| `[IgnoreMember]` | `[NinoIgnore]` |
| `AllowPrivate = true` | `[NinoType(includeNonPublicMembers: true)]` |
| `[SerializationConstructor]` | `[NinoConstructor]` ([Constructors](/en/docs/v4/constructors)) |
| `[Union(key, typeof(T))]` on the base | `[NinoType]` on the base: subtypes inherit it, with no keys ([Polymorphism](/en/docs/v4/polymorphism)) |
| `IMessagePackSerializationCallbackReceiver` | `[NinoOnSerializing]` on the `OnBeforeSerialize` method and `[NinoOnDeserialized]` on `OnAfterDeserialize`, with no interface ([Callbacks](/en/docs/v4/defining-types#callbacks)) |
| `IMessagePackFormatter<T>`, resolvers | [Custom Formatters](/en/docs/v4/custom-formatters) |
| `MessagePackSerializer.Serialize(value)` | `NinoSerializer.Serialize(value)` |
| `MessagePackSerializer.Serialize(bufferWriter, value)` | `NinoSerializer.Serialize(value, bufferWriter)`: the value comes first |
| `MessagePackSerializer.Deserialize<T>(bytes)` | `NinoDeserializer.Deserialize<T>(bytes)` |
| `MessagePackSerializer.SerializeAsync(stream, value)`, `DeserializeAsync<T>(stream)` | `NinoSerializer.SerializeAsync(value, stream)`, `NinoDeserializer.DeserializeAsync<T>(stream)`: the value comes first ([Async](/en/docs/v4/advanced/streams#async)) |
| `MessagePackStreamReader` | [frames](/en/docs/v4/advanced/streams#frames) on the stream |
| `MessagePackSecurity.UntrustedData` | nothing per call; `NinoSettings.Untrusted = true` once at startup for the extra checks ([Untrusted Mode](/en/docs/v4/security#untrusted-mode)) |
| `MessagePackCompression.Lz4BlockArray` | a compression stream over the output ([Compression](/en/docs/v4/advanced/streams#compression)) |

The two libraries write different bytes, so stored data has to be converted; both can be installed in one project while you do ([Switching to Nino](/en/docs/v4/compare#switching) has the steps). Keep both attributes on your types, read each stored value with MessagePack and write it again with Nino:

```csharp title="Messages.cs"
using MessagePack;
using Nino.Core;

[Union(0, typeof(Ping))]
[Union(1, typeof(Chat))]
[NinoType]                       // [!code ++]
public interface IMessage { }

[MessagePackObject]
public sealed class Ping : IMessage
{
    [Key(0)] public long SentAt { get; set; }
}

[MessagePackObject]
public sealed class Chat : IMessage
{
    [Key(0)] public string Text { get; set; }
    [IgnoreMember, NinoIgnore] public int Cached { get; set; }
}
```

```csharp
using MessagePack;

byte[] old = MessagePackSerializer.Serialize<IMessage>(new Chat { Text = "hi" });
IMessage message = MessagePackSerializer.Deserialize<IMessage>(old); // what MessagePack stored
byte[] bytes = NinoSerializer.Serialize(message);                    // written again with Nino
IMessage back = NinoDeserializer.Deserialize<IMessage>(bytes);       // a Chat
```
