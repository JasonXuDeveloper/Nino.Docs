[MessagePack for C#](https://github.com/MessagePack-CSharp/MessagePack-CSharp)（MessagePack-CSharp）是 .NET 里用得最广的二进制序列化库之一。它写的是 [MessagePack](https://msgpack.org) 格式，许多语言都有读取它的库。本页对比 Nino v4 和 MessagePack for C# **3.1.12**，也就是 Nino 基准测试所用的版本：MessagePack 的功能以它的 README 和源码为准，Nino 的功能以 Nino 源码为准；标注“实测”的行为，是用 3.1.12 写测试程序验证过的。MessagePack 已经公布了 4.0 预览版，本页讲的是 3.x。无法核实的功能，一律不列出。两者和 MemoryPack、protobuf、System.Text.Json 比起来怎样，见[序列化库选型](/zh/docs/v4/compare)。

## 两种格式 [#formats]

最根本的区别在字节本身。MessagePack 是自描述格式：每个值都带类型标记，任何 MessagePack 读取器不需要你的类型也能解析。Nino 的字节不带标记：怎么读由你的 C# 类型决定，在 .NET 里如此，在 [nino-gen](/zh/docs/v4/advanced/codegen) 从这些类型生成的 Go、Rust 和 TypeScript 代码里也一样。

| | Nino v4 | MessagePack for C# |
| --- | --- | --- |
| 一个值 | 只有它的字节 | 一个类型标记（整数、字符串、数组、映射……）加上它的字节 |
| 一个对象 | 成员依次排列；用 [`NinoFormat.Keyed`](/zh/docs/v4/evolving-data#keyed-members) 时每个成员多一个键和一个长度（8 字节） | 成员组成的数组（整数 `[Key]`），或从名字到成员的映射（字符串键） |
| 一个子类型 | 4 字节类型 ID，即类型名的哈希 | 两个元素的数组：先是 union 键，再是对象 |
| 整数 | 按完整宽度写（`int` 占 4 字节） | 用能装下这个值的最少字节写（0 到 127 只占 1 字节） |
| 字符串 | 所有字符都不超过 U+00FF 时每字符一个字节，否则 UTF-16；加 [`[NinoUtf8]`](/zh/docs/v4/defining-types#string-encoding) 用 UTF-8 | UTF-8 |
| `Guid`、`DateTime` | 16 字节；tick 和 kind | 36 个字符的字符串；UTC 的 MessagePack 时间戳（native 解析器可以改变这两者） |

## 性能 [#performance]

用 BenchmarkDotNet 测量，与 Nino 在同一轮测试中运行，数据和类型都相同；MessagePack 用的是它的文档为速度推荐的 API，格式化器由它的源生成器生成（[测试设置](/zh/docs/v4/benchmarks#messagepack-and-protobuf-net)）。<IfWorkloads>在 Nino 领先的[真实负载](/zh/docs/v4/benchmarks#workloads)上，序列化快 <BenchValue k="workloads.messagepack.serialize" />，反序列化快 <BenchValue k="workloads.messagepack.deserialize" />。</IfWorkloads><IfWorkloads not>在 Nino 领先的类和多态类型上，序列化快 <BenchValue k="messagepack.serialize" />，反序列化快 <BenchValue k="messagepack.deserialize" />。</IfWorkloads>MessagePack 无法用相同数据表达的用例（引用追踪、读入已有实例、泛型基类型）不计在内。

<LibrarySummary lib="messagepack" lang="zh" />

载荷大小的差别来自格式本身：MessagePack 用更少的字节写小整数，把 `Guid` 写成字符串；Nino 按完整宽度写整数，`Guid` 占 16 字节。

## 不可信输入 [#untrusted-input]

MessagePack 的 README 警告：“取决于反序列化时使用的设置，不可信数据可能执行任意代码，或造成拒绝服务攻击”（"depending on the settings used during deserialization, untrusted data may be able to execute arbitrary code or cause a denial of service attack"），并要求读这类数据时主动切换到更安全的模式：`MessagePackSerializerOptions.Standard.WithSecurity(MessagePackSecurity.UntrustedData)`，每次调用时传入，或者设为 `MessagePackSerializer.DefaultOptions`。默认选项用的是 `MessagePackSecurity.TrustedData`。README 说这个模式只是“针对一些常见攻击”做了加固，“本身并不是完全安全的方案”，还说不要用 Typeless API 读不可信数据，因为它会把类型名写进数据（[MessagePack README，Security](https://github.com/MessagePack-CSharp/MessagePack-CSharp#security)）。

Nino 的默认模式就能读不可信数据；[`NinoSettings.Untrusted`](/zh/docs/v4/security#untrusted-mode) 再加上那些每次读取都要多花时间的检查。

## MessagePack 领先的地方 [#where-messagepack-is-ahead]

下面这些 MessagePack 能做，Nino v4 不做：

- **任何语言都能读。** MessagePack 是标准格式，许多语言都有它的库，不需要你的类型也能读：用 `ConvertToJson` 转成 JSON，或用 `Deserialize<dynamic>`。Nino 的数据要通过你的 C# 类型读，或者通过从这些类型生成的 Go、Rust 和 TypeScript 代码读。
- **可以不加特性。** `ContractlessStandardResolver` 按成员名写出任何公共类型，用起来很像 JSON 序列化库。
- **小整数更小。** 小的数字占的字节比它的完整宽度少。
- **`System.Type` 值和无类型数据**，仅限可信数据。
- **按调用传选项**：`MessagePackSerializerOptions` 按调用选择解析器、安全模式和压缩。
- **内置压缩**：LZ4 是每次调用的一个选项。
- **基于它的框架**：MagicOnion（代码优先的 gRPC）和 StreamJsonRpc。

Nino 不做的事有什么替代做法，见[局限](/zh/docs/v4/compare#limitations)。什么场景选哪个：[怎么选](/zh/docs/v4/compare#which-to-choose)。

## 从 MessagePack 迁移 [#switching-from-messagepack]

| MessagePack | Nino |
| --- | --- |
| `[MessagePackObject]` | `[NinoType]` |
| 每个成员上的 `[Key(0)]`、`[Key(1)]`…… | 不需要：按声明顺序写出公共成员；或者用 `[NinoType(false)]`，在要写的成员上加 `[NinoMember(n)]`（[显式指定成员](/zh/docs/v4/defining-types#choosing-members-explicitly)） |
| `[Key("name")]`、`keyAsPropertyName: true` | `[NinoType(format: NinoFormat.Keyed)]`：按名字识别成员，用 `[NinoFormerName]` 重命名（[键控成员](/zh/docs/v4/evolving-data#keyed-members)） |
| `[IgnoreMember]` | `[NinoIgnore]` |
| `AllowPrivate = true` | `[NinoType(includeNonPublicMembers: true)]` |
| `[SerializationConstructor]` | `[NinoConstructor]`（[构造函数](/zh/docs/v4/constructors)） |
| 基类型上的 `[Union(key, typeof(T))]` | 基类型上的 `[NinoType]`：子类型自动继承，不需要键（[多态](/zh/docs/v4/polymorphism)） |
| `IMessagePackSerializationCallbackReceiver` | 给 `OnBeforeSerialize` 方法加 `[NinoOnSerializing]`，给 `OnAfterDeserialize` 加 `[NinoOnDeserialized]`，不用实现接口（[回调](/zh/docs/v4/defining-types#callbacks)） |
| `IMessagePackFormatter<T>`、解析器 | [自定义格式化器](/zh/docs/v4/custom-formatters) |
| `MessagePackSerializer.Serialize(value)` | `NinoSerializer.Serialize(value)` |
| `MessagePackSerializer.Serialize(bufferWriter, value)` | `NinoSerializer.Serialize(value, bufferWriter)`：值在前 |
| `MessagePackSerializer.Deserialize<T>(bytes)` | `NinoDeserializer.Deserialize<T>(bytes)` |
| `MessagePackSerializer.SerializeAsync(stream, value)`、`DeserializeAsync<T>(stream)` | `NinoSerializer.SerializeAsync(value, stream)`、`NinoDeserializer.DeserializeAsync<T>(stream)`：值在前（[异步](/zh/docs/v4/advanced/streams#async)） |
| `MessagePackStreamReader` | 在流上读写[帧](/zh/docs/v4/advanced/streams#frames) |
| `MessagePackSecurity.UntrustedData` | 每次调用都不用传；要额外的检查，在启动时设一次 `NinoSettings.Untrusted = true`（[不可信模式](/zh/docs/v4/security#untrusted-mode)） |
| `MessagePackCompression.Lz4BlockArray` | 在输出外面套一个压缩流（[压缩](/zh/docs/v4/advanced/streams#compression)） |

两个库写出的字节不同，所以已经存下的数据需要转换；转换期间两个库可以装在同一个项目里（步骤见[换成 Nino](/zh/docs/v4/compare#switching)）。类型上同时保留两种特性，用 MessagePack 读出每个存下的值，再用 Nino 写回：

```csharp title="Messages.cs"
using MessagePack;
using Nino.Core;

[Union(0, typeof(Ping))]
[Union(1, typeof(Chat))]
[NinoType]                       // [!code ++]
public interface IMessage { }

[MessagePackObject]
public sealed class Ping : IMessage
{
    [Key(0)] public long SentAt { get; set; }
}

[MessagePackObject]
public sealed class Chat : IMessage
{
    [Key(0)] public string Text { get; set; }
    [IgnoreMember, NinoIgnore] public int Cached { get; set; }
}
```

```csharp
using MessagePack;

byte[] old = MessagePackSerializer.Serialize<IMessage>(new Chat { Text = "hi" });
IMessage message = MessagePackSerializer.Deserialize<IMessage>(old); // MessagePack 存下的数据
byte[] bytes = NinoSerializer.Serialize(message);                    // 用 Nino 重新写出
IMessage back = NinoDeserializer.Deserialize<IMessage>(bytes);       // 一个 Chat
```
