Rust 运行时（crate `nino-serialization`，库名 `nino`）读写 Nino 的[二进制格式](/zh/docs/v4/wire-format)：Rust 程序与你的 .NET 代码交换相同的字节。它不含 `unsafe` 代码（`#![forbid(unsafe_code)]`），没有必需的依赖，需要 Rust 1.88 或更高版本。它位于 Nino 的仓库中（[runtimes/rust](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/rust)），尚未发布到 crates.io，并用与 .NET、TypeScript 和 Go 相同的一致性语料测试。在发布之前，请从 Git 依赖它：

```toml title="Cargo.toml"
[dependencies]
nino-serialization = { git = "https://github.com/JasonXuDeveloper/Nino", features = ["indexmap"] }
```

```rust
let bytes = nino::serialize(&vec![1i32, 2])?;
let back: Vec<i32> = nino::deserialize_exact(&bytes)?;
```

| 函数 | |
| --- | --- |
| `serialize`、`serialize_into` | 按声明类型写出一个值，与 `NinoSerializer.Serialize<T>` 相同。`serialize_into` 追加到一个 `Vec`，出错时把它截回原来的长度。 |
| `deserialize`、`deserialize_exact` | 读取一个值。`deserialize_exact` 还会拒绝值之后的字节。 |

给 Rust 类型提供编解码器有两种方式：

- **生成的代码**：[nino-gen](/zh/docs/v4/advanced/codegen#rust) 为构建好的程序集中的每个 `[NinoType]` 写出一个 Rust 类型及其编解码器。
- **`#[derive(NinoRead, NinoWrite)]`**（功能 `derive`）用于你自己写的类型，在编译时与类型发布的布局核对。

## 类型 [#types]

| C# | Rust |
| --- | --- |
| `sbyte` … `ulong`、`Int128`、`UInt128`、`float`、`double`、`bool` | `i8` … `u64`、`i128`、`u128`、`f32`、`f64`、`bool` |
| `char` | `u16`，一个 UTF-16 码元（Rust 的 `char` 对应 `Rune`） |
| `string` | `Option<String>`、`Option<WideString>`，`[NinoUtf8]` 则为 `Option<Utf8>` |
| `T?`（结构体）、类 | `Option<T>`；递归的类为 `Option<Box<T>>` |
| `T[]`、`List<T>`、`Queue<T>`…… | `Option<Vec<T>>`、`VecDeque<T>` |
| `HashSet<T>`、`SortedSet<T>` | `HashSet<T>`、`BTreeSet<T>`、`IndexSet<T>` |
| `Dictionary<K, V>`、`SortedDictionary<K, V>` | `HashMap<K, V>`、`BTreeMap<K, V>`、`IndexMap<K, V>` |
| `ValueTuple<…>`（1 到 7 项） | 元组 |
| `T[,]` 等多维数组 | `Grid<T, R>` |
| `decimal`、`Guid`、`DateTime`、`DateTimeOffset`、`TimeSpan`、`DateOnly`、`TimeOnly`、`Half`、`Rune`、`Version`、`BigInteger`、`BitArray` | 同名类型 |

多态的声明类型（抽象类、接口、非密封类）是一个 Rust 枚举，每个具体类型一个变体；其他类型 ID 都会被拒绝。

`String` 把未配对的代理项（.NET 字符串可能包含）替换为 U+FFFD；`WideString` 保留 UTF-16 码元，所以这样的值能逐字节写回。

## Derive [#derive]

```rust
use nino::{NinoRead, NinoWrite};

#[derive(Debug, Default, Clone, PartialEq, NinoRead, NinoWrite)]
#[nino(format = "keyed")]                 // [NinoType(NinoFormat.Keyed)] 密封类
pub struct Player {
    #[nino(key = "Name", utf8)]           // [NinoUtf8]
    pub name: Option<String>,
    #[nino(former = "Health")]            // 键为 "Hp"，也按 "Health" 读取
    pub hp: i32,
    #[nino(skip)]                         // 不在线上，读取时为 Default
    pub cached: u64,
}

#[derive(Debug, Default, Clone, Copy, PartialEq, NinoRead, NinoWrite)]
#[nino(kind = "raw")]                     // 非托管结构体，按规范布局
pub struct Vec2 { pub x: f32, pub y: f32 }
```

| 类型属性 | 含义 |
| --- | --- |
| `format = "plain" \| "tolerant" \| "keyed"` | `NinoFormat.Positional`（默认）、`VersionTolerant` 或 `Keyed`。 |
| `kind = "class" \| "open" \| "struct" \| "raw"` | 密封类（默认，带存在字节）、非密封类（带类型 ID）、结构体，或按内存写出的非托管结构体（可用 `pack` 和 `size`）。 |
| `id = "Full.Name"` 或 `id = 0x…` | 类型 ID：在编译时哈希的 .NET 全名，或数字本身。 |
| `deferrable = false` | .NET 从不延迟的类型（记录、通过构造函数创建的类型）。未给出时取自 `layout`。 |
| `layout = "…"` | 类型发布的[布局](/zh/docs/v4/evolving-data#layout-metadata)，在编译时核对：成员名字和顺序、键、旧键、`[NinoUtf8]`、原始值的大小和偏移。格式、种类、类型 ID 和可延迟性未给出时取自它。 |

字段属性有 `index`、`name`（.NET 中的名字；默认是字段名的 PascalCase 形式）、`key`、`former`、`utf8` 和 `skip`。枚举是多态的声明类型，每个具体类型一个变体。二进制格式无法表达的内容（`usize`、Rust 的 `char`、引用、冲突的键、不匹配的 `layout`）都是指明字段的编译错误。

## 功能 [#features]

| 功能 | 增加 |
| --- | --- |
| `derive` | `#[derive(NinoRead, NinoWrite)]`（crate `nino-serialization-derive`） |
| `indexmap` | `IndexMap` 和 `IndexSet`，保持线上顺序，所以映射能读回并逐字节写回。nino-gen 生成的代码需要它。 |
| `serde` | 为运行时的值类型实现 serde，带 Nino 编解码器的类型也能派生 serde（`nino-gen --serde`） |
| `uuid`、`rust_decimal`、`chrono`、`num-bigint` | Nino 的 `Guid`、`decimal`、日期时间类型和 `BigInteger` 与这些 crate 类型之间的转换 |

## 保证 [#guarantees]

读取器与 .NET 读取器一样，假定输入可能是恶意的（[不可信数据](/zh/docs/v4/security)）：

- 它不会 panic，不会越界读取，要么返回完整的值，要么返回一个 `Error`（`ErrorKind` 说明是哪项检查失败）。
- 它最多递归 128 层类主体；更深的主体像 .NET 一样被延迟到堆上的工作列表，嵌套在 512 层处停止（`ErrorKind::TooDeep`）。
- 内存受输入限制：集合的预先分配来自每次读取的一份预算（每个输入字节 16 字节，外加 4 KiB），剩余输入填不满的数量在分配任何内存之前就失败。
- 它拒绝 .NET 在任何模式下都拒绝的内容（不是 0 或 1 的 bool 和存在字节、集合和映射中的重复键、留下字节的键控成员、格式错误的延迟主体段），还拒绝 .NET 在[不可信模式](/zh/docs/v4/security#untrusted-mode)之外或总是接受的字节：超出范围的日期和时间、无效的 `decimal`、原始结构体中非零的填充、`BitArray` 中不为零的未用位、非最简形式的 `BigInteger`。

不支持引用追踪（`trackReferences: true`）。完整的 API、每种值类型的 serde 形式，以及测试和模糊测试的运行方式见运行时的 [README](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/rust)。
