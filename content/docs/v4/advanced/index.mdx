## Which Guide Do I Need? [#which-guide-do-i-need]

| You are building | Start with |
| --- | --- |
| A service protocol, a real-time server (trading, collaboration, games), a WebSocket or UDP link | [Network Layer](/en/docs/v4/advanced/networking) |
| gRPC services without `.proto` files, between .NET peers | [gRPC](/en/docs/v4/advanced/networking#grpc) |
| An ASP.NET Core API (MVC or Minimal APIs) that takes and returns Nino bodies | [ASP.NET Core](/en/docs/v4/advanced/aspnetcore) |
| A web or Node front end (JavaScript or TypeScript) that talks to a Nino server | [TypeScript Clients](/en/docs/v4/advanced/typescript), or [Browser and JavaScript Clients](/en/docs/v4/advanced/browser) to run the C# types themselves |
| Producers and consumers on Kafka, RabbitMQ or another broker | [Message Queues and Event Streams](/en/docs/v4/advanced/message-queues) |
| Telemetry, metrics or market-data feeds | [Telemetry and Tick Streams](/en/docs/v4/advanced/message-queues#telemetry-and-tick-streams) |
| A Redis or `IDistributedCache` layer, or an in-process cache of blobs | [Caching](/en/docs/v4/advanced/caching) |
| Files, documents, save data, local key-value stores | [Persistence](/en/docs/v4/advanced/persistence) |
| An event store, a journal, snapshots or checkpoints | [Append-Only Logs](/en/docs/v4/advanced/persistence#append-only-logs) |
| IPC over named pipes or sockets | [Framed Streams](/en/docs/v4/advanced/zero-allocation#framed-streams) |
| Records in shared or memory-mapped files | [Fixed-Size Records](/en/docs/v4/advanced/zero-allocation#fixed-size-records) |
| A Unity, Godot or HybridCLR project | [Unity and HybridCLR](/en/docs/v4/advanced/unity), [Godot](/en/docs/v4/platforms#godot) |

## Which Feature Do I Need?

| You want to | Use |
| --- | --- |
| Add members to a saved type later | [`format: NinoFormat.VersionTolerant`](/en/docs/v4/evolving-data#version-tolerance) |
| Reorder, remove or insert members later | [`format: NinoFormat.Keyed`](/en/docs/v4/evolving-data#keyed-members) |
| Rename a type or move it to another namespace | [`[NinoFormerName]`](/en/docs/v4/defining-types#former-name) |
| Keep shared references or cycles | [`trackReferences: true`](/en/docs/v4/reference-tracking) |
| Stop allocating on every deserialization | [reuse deserialization and `[NinoPooled]`](/en/docs/v4/pooling) |
| Serialize a type Nino does not know | [`[assembly: NinoFormatter]`](/en/docs/v4/custom-formatters) |
| Encode one member differently | [`[NinoCustomFormatter]`](/en/docs/v4/custom-formatters#for-one-member) |
| Read a value as the type it really is | [Polymorphism](/en/docs/v4/polymorphism) |
| Serialize a type known only at run time | [Runtime types](/en/docs/v4/basic#runtime-types) |
| Write several values into one buffer | [`Writer` and `Reader`](/en/docs/v4/basic#several-values-in-one-buffer) |
| Read from or write to a `Stream`, async | [Streams and async](/en/docs/v4/advanced/streams#streams) |
| Run code before serializing or after deserializing | [Callbacks](/en/docs/v4/advanced/streams#callbacks) |
| Compress the output | [Compression](/en/docs/v4/advanced/streams#compression) |
| Check that a type's bytes did not change between builds | [Layout metadata](/en/docs/v4/evolving-data#layout-metadata) |
| Rent serialization buffers from your own `ArrayPool<byte>` | [`NinoArrayBufferWriter`](/en/docs/v4/basic#reusing-a-buffer) |
| Hot-reload logic in a collectible `AssemblyLoadContext` | [Unloading assemblies](/en/docs/v4/platforms#unloading-assemblies) |
| Publish trimmed or with Native AOT | [Trimming and Native AOT](/en/docs/v4/platforms#trimming-and-native-aot) |
