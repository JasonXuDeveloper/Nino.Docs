The Rust runtime (crate `nino-serialization`, library `nino`) reads and writes Nino's [wire format](/en/docs/v4/wire-format): a Rust program exchanges the same bytes as your .NET code. It has no `unsafe` code (`#![forbid(unsafe_code)]`) and no required dependencies, and needs Rust 1.88 or later. It lives in Nino's repository ([runtimes/rust](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/rust)), is not published on crates.io yet, and is tested against the same conformance corpus as .NET, TypeScript and Go. Until it is published, depend on it from Git:

```toml title="Cargo.toml"
[dependencies]
nino-serialization = { git = "https://github.com/JasonXuDeveloper/Nino", features = ["indexmap"] }
```

```rust
let bytes = nino::serialize(&vec![1i32, 2])?;
let back: Vec<i32> = nino::deserialize_exact(&bytes)?;
```

| Function | |
| --- | --- |
| `serialize`, `serialize_into` | Write a value under its declared type, as `NinoSerializer.Serialize<T>` does. `serialize_into` appends to a `Vec`, and on an error truncates it back to where it was. |
| `deserialize`, `deserialize_exact` | Read a value. `deserialize_exact` also rejects bytes after it. |

There are two ways to give Rust types their codecs:

- **Generated code**: [nino-gen](/en/docs/v4/advanced/codegen#rust) writes a Rust type and its codecs for every `[NinoType]` of a built assembly.
- **`#[derive(NinoRead, NinoWrite)]`** (feature `derive`) on types you write yourself, checked against the type's published layout at compile time.

## Types [#types]

| C# | Rust |
| --- | --- |
| `sbyte` … `ulong`, `Int128`, `UInt128`, `float`, `double`, `bool` | `i8` … `u64`, `i128`, `u128`, `f32`, `f64`, `bool` |
| `char` | `u16`, a UTF-16 code unit (a Rust `char` is a `Rune`) |
| `string` | `Option<String>`, `Option<WideString>`, or `Option<Utf8>` for `[NinoUtf8]` |
| `T?` (a struct), a class | `Option<T>`; `Option<Box<T>>` for a recursive class |
| `T[]`, `List<T>`, `Queue<T>`, … | `Option<Vec<T>>`, `VecDeque<T>` |
| `HashSet<T>`, `SortedSet<T>` | `HashSet<T>`, `BTreeSet<T>`, `IndexSet<T>` |
| `Dictionary<K, V>`, `SortedDictionary<K, V>` | `HashMap<K, V>`, `BTreeMap<K, V>`, `IndexMap<K, V>` |
| `ValueTuple<…>` (1 to 7 items) | tuples |
| `T[,]` and other multi-dimensional arrays | `Grid<T, R>` |
| `decimal`, `Guid`, `DateTime`, `DateTimeOffset`, `TimeSpan`, `DateOnly`, `TimeOnly`, `Half`, `Rune`, `Version`, `BigInteger`, `BitArray` | types of the same names |

A polymorphic declared type (an abstract class, an interface, a class that is not sealed) is a Rust enum with one variant per concrete type; any other type id is rejected.

`String` replaces an unpaired surrogate (which a .NET string may hold) with U+FFFD; `WideString` keeps the UTF-16 code units, so such a value writes back byte for byte.

## Derive [#derive]

```rust
use nino::{NinoRead, NinoWrite};

#[derive(Debug, Default, Clone, PartialEq, NinoRead, NinoWrite)]
#[nino(format = "keyed")]                 // [NinoType(NinoFormat.Keyed)] sealed class
pub struct Player {
    #[nino(key = "Name", utf8)]           // [NinoUtf8]
    pub name: Option<String>,
    #[nino(former = "Health")]            // keyed "Hp", and read under "Health" too
    pub hp: i32,
    #[nino(skip)]                         // not on the wire, Default on read
    pub cached: u64,
}

#[derive(Debug, Default, Clone, Copy, PartialEq, NinoRead, NinoWrite)]
#[nino(kind = "raw")]                     // an unmanaged struct, in the canonical layout
pub struct Vec2 { pub x: f32, pub y: f32 }
```

| Type attribute | Meaning |
| --- | --- |
| `format = "plain" \| "tolerant" \| "keyed"` | `NinoFormat.Positional` (default), `VersionTolerant` or `Keyed`. |
| `kind = "class" \| "open" \| "struct" \| "raw"` | A sealed class (default, behind a presence byte), a class that is not sealed (behind its type id), a struct, or an unmanaged struct written as its memory (with `pack` and `size`). |
| `id = "Full.Name"` or `id = 0x…` | The type id: a .NET full name hashed at compile time, or the number. |
| `deferrable = false` | A type .NET never defers (a record, a type built through its constructor). Taken from `layout` when not given. |
| `layout = "…"` | The type's published [layout](/en/docs/v4/evolving-data#layout-metadata), checked at compile time: member names and order, keys, former keys, `[NinoUtf8]`, raw sizes and offsets. Format, kind, type id and deferrability come from it when not given. |

Field attributes are `index`, `name` (the .NET name; the default is the field's name in PascalCase), `key`, `former`, `utf8` and `skip`. An enum is a polymorphic declared type, one variant per concrete type. Anything the wire format cannot express (`usize`, a Rust `char`, references, colliding keys, a `layout` that does not match) is a compile error naming the field.

## Features [#features]

| Feature | Adds |
| --- | --- |
| `derive` | `#[derive(NinoRead, NinoWrite)]` (crate `nino-serialization-derive`) |
| `indexmap` | `IndexMap` and `IndexSet`, which keep the wire order, so a map reads back and writes back byte for byte. Needed by code nino-gen generates. |
| `serde` | serde for the runtime's value types, so types with Nino codecs can derive serde too (`nino-gen --serde`) |
| `uuid`, `rust_decimal`, `chrono`, `num-bigint` | Conversions between Nino's `Guid`, `decimal`, date and time types and `BigInteger` and those crates' types |

## Guarantees [#guarantees]

The reader assumes the input may be hostile, as the .NET reader does ([Untrusted Data](/en/docs/v4/security)):

- It never panics and never reads out of bounds, and returns either the whole value or an `Error` (`ErrorKind` says which check failed).
- It recurses at most 128 class bodies deep; deeper bodies are deferred onto a heap work list, as .NET defers them, and nesting stops at 512 (`ErrorKind::TooDeep`).
- Memory is bounded by the input: up-front allocation for collections comes from one budget per read (16 bytes per input byte, plus 4 KiB), and a count the remaining input cannot fill fails before anything is allocated.
- It rejects what .NET rejects in every mode (bools and presence bytes other than 0 or 1, duplicate keys in sets and maps, keyed members that leave bytes, malformed sections of deferred bodies), and also bytes .NET accepts outside [untrusted mode](/en/docs/v4/security#untrusted-mode) or always: out-of-range dates and times, invalid `decimal`s, non-zero padding in raw structs, unused `BitArray` bits that are not zero, non-minimal `BigInteger`s.

Reference tracking (`trackReferences: true`) is not supported. The runtime's [README](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/rust) has the full API, the serde forms of each value type and how the tests and fuzzing run.
