Go 运行时（模块 `github.com/JasonXuDeveloper/Nino/runtimes/go`，包 `nino`）读写 Nino 的[二进制格式](/zh/docs/v4/wire-format)：Go 服务与你的 .NET 代码交换相同的字节。它需要 Go 1.22 或更高版本，除标准库外没有任何依赖。它位于 Nino 的仓库中（[runtimes/go](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/go)），并用与 .NET、TypeScript 和 Rust 相同的一致性语料测试。

```shell
go get github.com/JasonXuDeveloper/Nino/runtimes/go
```

给 Go 类型提供编解码器有两种方式：

- **生成的代码**：[nino-gen](/zh/docs/v4/advanced/codegen#go) 为构建好的程序集中的每个 `[NinoType]` 写出一个 Go 结构体以及读写函数。不用反射，是最快的方式。
- **结构体标签**：像 `encoding/json` 那样，用 `nino` 标签映射你自己写的 Go 结构体，然后调用 `nino.Marshal` 和 `nino.Unmarshal`。

## 生成的代码 [#generated-code]

```shell
nino-gen --assembly bin/Release/net8.0/MyGame.Shared.dll --lang go --out ./protocol --package protocol
```

```go
data, err := nino.Serialize(player, protocol.WritePlayer)      // 新的切片
buf, err = nino.Append(buf[:0], player, protocol.WritePlayer)  // 追加；buf 有空间时不分配
player, err := nino.Deserialize(data, protocol.ReadPlayer)      // 忽略值之后的字节，与 .NET 一致
player, err := nino.DeserializeExact(data, protocol.ReadPlayer) // ……或拒绝它们
```

每个 `[NinoType]` 都有一个 `ReadX` 和 `WriteX` 函数。密封类是 `*X`（nil 表示 null），结构体是 `X`，可以容纳多种类型的槽位（抽象类、接口、非密封类）是一个接口，每个允许的类型一个实现。生成的结构体也带有 `nino` 标签和 `NinoLayout()`，所以下面的结构体标签方式同样能读写它们。

## 结构体标签 [#struct-tags]

```go
type Monster struct {
	Health int32   `nino:"Health"`
	Name   *string `nino:"Name,former=Title"`
	Items  []int32 `nino:"Items"`
	Cache  string  `nino:"-"`
}

func (Monster) NinoLayout() string { // .NET 为该类型发布的布局，或其中一部分
	return "format=Keyed; header=NullFlag"
}

data, err := nino.Marshal(m)          // m 是 *Monster：一个密封类
err = nino.Unmarshal(data, &m)        // 出错时 *m 保持不变
err = nino.UnmarshalExact(data, &m)   // ……并且值之后的字节视为错误
data, err = nino.MarshalAs[Animal](a) // 多态根，按类型 ID 写出
```

| 标签 | 含义 |
| --- | --- |
| `nino:"0"`、`nino:"1"`…… | 成员的位置，用于按位置和版本容错的类型：0 到 n-1，不能有空缺或重复。 |
| `nino:"Name"` | 键控类型的成员，用其 C# 名字。 |
| `nino:"-"` | 只在 Go 中使用的字段：不读也不写。 |
| `,utf8` | `[NinoUtf8]` 字符串。 |
| `,former=Old` | 键控成员的旧名称，每个名称写一次。 |

类型用 `NinoLayout() string` 方法声明它在 .NET 中的形状：.NET 为它发布的[布局](/zh/docs/v4/evolving-data#layout-metadata)（`format=`、`header=`、`typeId=`、`deferrable=`、`members=`），或其中的部分。给出 `members=` 时，标签会与之核对：成员数量、每个字段的编码和键。多态类型用 `nino.Register` 注册一次，槽位只读取实现了它的接口的已注册类型。

二进制格式无法表达的内容（没有固定大小的 `int` 字段、`omitempty`、`trackReferences=true` 的类型）会在读写任何字节之前返回一个指明字段的 `*nino.TagError`。每个类型的计划只构建一次并缓存；之后序列化的耗时是生成代码的几倍，仍然比 `encoding/json` 快。完整的标签说明和每种编码对应的 Go 类型见运行时的 [README](https://github.com/JasonXuDeveloper/Nino/tree/main/runtimes/go#struct-tags)。

## 保证 [#guarantees]

读取器与 .NET 读取器一样，按不可信输入处理数据（[不可信数据](/zh/docs/v4/security)）：

- **不会 panic。** 对任何输入，读取都不会 panic，也不会读到数据之外，这是由构造保证的，而不是靠 `recover`。错误是粘滞的：第一次失败后，每次读取都返回零值，所以每个循环都会结束。
- **内存有界。** 每个长度在分配任何内存之前都与剩余字节比较，上限与 .NET 相同。
- **深度有界。** 超过 128 层的类主体完全按 .NET 的方式延迟，所以字节一致、栈有界；不能延迟的超过 512 层就失败。
- **受限的多态。** 只接受指向该槽位允许类型的类型 ID；从不按名字查找类型。
- **一种错误类型。** 所有失败都是 `*nino.Error`（`Code`、`Offset`、`Detail`；`errors.Is(err, nino.ErrTooDeep)` ……），`Deserialize` 同时返回零值，从不返回部分值。
- **严格的字节。** 它拒绝 .NET 在任何模式下都拒绝的内容（不是 0 或 1 的 bool 和存在字节、留下字节的键控成员、格式错误的延迟主体段、映射或集合中的重复键），还拒绝 .NET 在[不可信模式](/zh/docs/v4/security#untrusted-mode)之外或总是接受的字节：超过 `DateTime.MaxValue` 的 `DateTime` 刻度、无效的 `decimal`、超出范围的 `DateOnly` 和 `TimeOnly`、原始结构体中不是 0 或 1 的 bool、键控主体中的重复键、非最简形式的 `BigInteger`。

把值写入复用的缓冲区时不分配内存。

## 字符串 [#strings]

默认编码的字符串以 WTF-8 读入 Go 字符串：即 UTF-8，但未配对的代理项（.NET 字符串可能包含）保留为 3 字节形式，所以写回时得到相同的码元。`Reader.UTF16` 返回码元本身。`[NinoUtf8]` 字符串是严格的 UTF-8。

## 不支持的内容 [#not-supported]

引用追踪（`trackReferences: true`）没有实现，与 TypeScript 相同。结构体标签方式还拒绝多维数组、分组、`BitArray`、`TimeZoneInfo`、自定义格式化器，以及带成员的 `[NinoType]` 集合；生成的代码覆盖 [nino-gen 生成的内容](/zh/docs/v4/advanced/codegen#not-generated)。
