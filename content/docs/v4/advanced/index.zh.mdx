## 其他语言 [#other-languages]

其他语言的客户端和服务依据构建好的程序集中的[布局元数据](/zh/docs/v4/evolving-data#layout-metadata)，读写与 .NET 相同的字节。它们共用的格式见[二进制格式](/zh/docs/v4/wire-format)。

<Cards>
  <Card icon={<Languages />} title="TypeScript、Go 与 Rust" href="/zh/docs/v4/advanced/codegen">
    Nino.Codegen 在每次构建后（或用 `nino-gen` 基于构建好的程序集）把你的 `[NinoType]` 写成 TypeScript、Go 或 Rust 类型和编解码器，字节与 .NET 相同。支持 Go 结构体标签和 Rust derive，读取器能安全处理不可信数据。
  </Card>
</Cards>
