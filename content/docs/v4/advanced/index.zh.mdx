功能页面讲每个选项的作用；这些指南按你实际要做的系统把它们组合起来，给出可以直接复制的完整做法。所有代码片段只用到 Nino 的公开 API 和标准 .NET 类型；涉及第三方客户端（Redis、Kafka、gRPC）的地方只做最简示意。

## 引擎与语言 [#other-languages]

Unity 和 Godot 各有自己的配置方式，浏览器也可以在 .NET WebAssembly 上直接运行你的 C# 类型。其他语言的客户端和服务依据构建出的程序集里的[布局元数据](/zh/docs/v4/evolving-data#layout-metadata)与 .NET 互通，共用的格式见[二进制格式](/zh/docs/v4/wire-format)。

<Cards>
  <Card icon={<Gamepad2 />} title="Unity 与 HybridCLR" href="/zh/docs/v4/advanced/unity">
    项目配置、程序集定义、Unity 的类、IL2CPP、热更新，以及降低帧耗时的技巧。
  </Card>
  <Card icon={<Joystick />} title="Godot" href="/zh/docs/v4/advanced/godot">
    Godot 4 .NET 项目：Godot 的结构体、节点与资源、存档、多人联机消息、在编辑器中重新构建。
  </Card>
  <Card icon={<Globe />} title="浏览器客户端" href="/zh/docs/v4/advanced/browser">
    在浏览器中使用同一套 `[NinoType]` 类型：一个带 `[JSExport]` 函数的 .NET WebAssembly 模块，供 JavaScript 或 TypeScript 调用。
  </Card>
  <Card icon={<Languages />} title="TypeScript、Go 与 Rust" href="/zh/docs/v4/advanced/codegen">
    Nino.Codegen 在每次构建后（或用 `nino-gen` 基于构建好的程序集）把你的 `[NinoType]` 写成 TypeScript、Go 或 Rust 类型和编解码器，与 .NET 互通。支持 Go 结构体标签和 Rust derive，读取器能安全处理不可信数据。
  </Card>
</Cards>

| 你想要 | 使用 |
| --- | --- |
| 以后给已保存的类型添加成员 | [`format: NinoFormat.VersionTolerant`](/zh/docs/v4/evolving-data#version-tolerance) |
| 以后重排、删除或插入成员 | [`format: NinoFormat.Keyed`](/zh/docs/v4/evolving-data#keyed-members) |
| 给类型改名或换命名空间 | [`[NinoFormerName]`](/zh/docs/v4/evolving-data#former-name) |
| 保留共享引用或循环引用 | [`trackReferences: true`](/zh/docs/v4/reference-tracking) |
| 不再每次反序列化都分配内存 | [复用反序列化与 `[NinoPooled]`](/zh/docs/v4/pooling) |
| 序列化 Nino 不认识的类型 | [`[assembly: NinoFormatter]`](/zh/docs/v4/custom-formatters) |
| 用不同方式编码某个成员 | [`[NinoMemberFormatter]`](/zh/docs/v4/custom-formatters#for-one-member) |
| 按值的真实类型读回 | [多态](/zh/docs/v4/polymorphism) |
| 序列化运行时才知道的类型 | [运行时类型](/zh/docs/v4/basic#runtime-types) |
| 在一个缓冲区里写入多个值 | [`Writer` 与 `Reader`](/zh/docs/v4/basic#several-values-in-one-buffer) |
| 读写 `Stream`，或异步读写 | [流与异步](/zh/docs/v4/advanced/streams#streams) |
| 在序列化前或反序列化后执行代码 | [回调](/zh/docs/v4/advanced/streams#callbacks) |
| 压缩输出 | [压缩](/zh/docs/v4/advanced/streams#compression) |
