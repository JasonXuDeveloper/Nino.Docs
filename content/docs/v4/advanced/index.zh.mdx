## 我需要哪个功能？ [#which-feature-do-i-need]

| 你想要 | 使用 |
| --- | --- |
| 之后向已保存的类型添加成员 | [`versionTolerant: true`](/zh/docs/v4/evolving-data#version-tolerance) |
| 之后重新排序、删除或插入成员 | [`keyed: true`](/zh/docs/v4/evolving-data#keyed-members) |
| 重命名类型或将其移到其他命名空间 | [`[NinoFormerName]`](/zh/docs/v4/defining-types#former-name) |
| 保留共享引用或循环引用 | [`trackReferences: true`](/zh/docs/v4/reference-tracking) |
| 不再每次反序列化都分配内存 | [引用反序列化与 `[NinoPooled]`](/zh/docs/v4/pooling) |
| 序列化 Nino 不认识的类型 | [`[assembly: NinoFormatter]`](/zh/docs/v4/custom-formatters) |
| 用不同方式编码某个成员 | [`[NinoCustomFormatter]`](/zh/docs/v4/custom-formatters#for-one-member) |
| 以值的真实类型读回 | [多态](/zh/docs/v4/polymorphism) |
