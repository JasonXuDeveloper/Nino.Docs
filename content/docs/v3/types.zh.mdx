本页列出 Nino 在运行时能序列化的类型，并介绍如何定义你自己的可序列化类型。

## 可序列化类型 [#serializable-types]

### 基础类型 [#primitive-types]

Nino 支持所有[非托管类型](https://learn.microsoft.com/zh-cn/dotnet/csharp/language-reference/builtin-types/unmanaged-types)，包括用户自定义的：
- `byte`、`short`、`int`、`long`、`float`、`double`
- `enum`
- `DateTime`、`Guid`
- 向量和矩阵类型
- 非托管结构体、非托管泛型结构体、非托管 record struct 和非托管泛型 record struct

`string` 也同样支持。

<Callout type="info" title="非托管结构体">

用户自定义的 `struct`、`struct<T>`（`T` 为非托管类型）、`record struct` 或 `record struct<T>`，只要所有字段都是非托管类型，它本身就是非托管类型，Nino 会自动序列化它。

Nino 会序列化这类结构体的全部字段，顺序就是字段的声明顺序（或由 `[StructLayout(LayoutKind.Explicit)]` 指定的布局）。不能排除某些字段，也不能指定反序列化时使用的构造函数。

</Callout>

### 自定义类型 [#custom-types]

要序列化托管类型（上面没列出的类型），给 `class`、`struct`、`record` 或 `record struct` 加上 `[NinoType]`，Nino 就会生成它的序列化和反序列化代码：

<Tabs items={["托管结构体", "Record", "Record struct", "类"]}>
<Tab value="托管结构体">

```csharp
[NinoType] // [!code highlight]
public struct SampleStruct
{
    public int Id;
    public string Name { get; set; }
}
```

</Tab>
<Tab value="Record">

```csharp
[NinoType] // [!code highlight]
public record SampleRecord(int Id, string Name);
```

</Tab>
<Tab value="Record struct">

```csharp
[NinoType] // [!code highlight]
public record struct SampleRecord(int Id, string Name);
```

</Tab>
<Tab value="类">

```csharp
[NinoType] // [!code highlight]
public class SampleClass
{
    public int Id;
    public string Name { get; set; }
}
```

</Tab>
</Tabs>

#### 选择成员 [#choosing-members]

`[NinoType]` 默认收集所有 public 字段，以及所有同时带 getter 和 setter 的 public 属性。对于 `record` 或 `record struct`，还会收集主构造函数的参数。

<TypeTable
  type={{
    autoCollect: {
      description: <><code>true</code>：自动收集成员。<code>false</code>：只收集标了 <code>[NinoMember(id)]</code> 的成员，按 <code>id</code> 从小到大排序。</>,
      type: 'bool',
      default: 'true',
    },
    containNonPublicMembers: {
      description: <>同时收集非 public 成员，如 <code>protected</code> 和 <code>private</code> 字段。</>,
      type: 'bool',
      default: 'false',
    },
  }}
/>

想自己决定序列化哪些成员，就给类型标上 `[NinoType(false)]`，再给要序列化的成员标上 `[NinoMember(id)]`。数字是成员的位置：成员按数字从小到大的顺序写入和读取。

<Tabs items={["类", "Record", "Record struct"]}>
<Tab value="类">

```csharp
[NinoType(false)] // [!code highlight]
public class SampleClass
{
    public int Id;
    [NinoMember(1)] // [!code highlight]
    public string Name { get; set; }
}
```

</Tab>
<Tab value="Record">

```csharp
[NinoType(false)] // [!code highlight]
public record SampleRecord(
    [NinoMember(2)] int Id, // [!code highlight]
    [NinoMember(1)] string Name); // [!code highlight]
```

</Tab>
<Tab value="Record struct">

```csharp
[NinoType(false)] // [!code highlight]
public record struct SampleRecordStruct(
    [NinoMember(2)] int Id, // [!code highlight]
    [NinoMember(1)] string Name); // [!code highlight]
```

</Tab>
</Tabs>

要收集 `protected`、`private` 字段等非 public 成员，传入 `containNonPublicMembers`：

```csharp
[NinoType(containNonPublicMembers: true)] // [!code highlight]
public class SampleClass
{
    private int Id;
}
```

开启自动收集时，给字段或属性标上 `[NinoIgnore]` 即可跳过它（比如某个 private 成员）。没有开启自动收集时，`[NinoIgnore]` 不起作用。

```csharp
[NinoType] // [!code highlight]
public class SampleClass
{
    [NinoIgnore] // [!code highlight]
    public int Id;
    public string Name { get; set; }
}
```

<Callout type="warn">

`[NinoIgnore]` 对 record 的主构造函数参数**无效**，对非托管结构体的字段也**无效**。

</Callout>

### 泛型类型 [#generic-types]

Nino 支持序列化和反序列化泛型类型：

<Tabs items={["泛型结构体", "泛型类", "泛型 record", "泛型 record struct"]}>
<Tab value="泛型结构体">

```csharp
[NinoType] // [!code highlight]
public struct GenericStruct<T>
{
    public T Val;
}
```

</Tab>
<Tab value="泛型类">

```csharp
[NinoType] // [!code highlight]
public class Generic<T>
{
    public T Val;
}
```

</Tab>
<Tab value="泛型 record">

```csharp
[NinoType] // [!code highlight]
public record SimpleRecord6<T>(int Id, T Data);
```

</Tab>
<Tab value="泛型 record struct">

```csharp
[NinoType] // [!code highlight]
public record struct SimpleRecordStruct2<T>(int Id, T Data);
```

</Tab>
</Tabs>

支持给类型参数加约束：

```csharp
[NinoType] // [!code highlight]
public class ComplexGeneric<T> where T : IList // [!code highlight]
{
    public T Val;
}
```

也支持类型由类型参数构成的成员：

```csharp
[NinoType] // [!code highlight]
public class ComplexGeneric2<T>
{
    public Generic<T> Val; // [!code highlight]
}
```

<Callout type="warn">

Nino 在泛型类型被具体的类型参数实例化的地方生成它的序列化代码，所以请确保这些类型参数都是可序列化的类型：

```csharp
Generic<int> generic = new Generic<int>();
Generic<string> generic = new Generic<string>();
Generic<List<int>> generic = new Generic<List<int>>();
```

</Callout>

### 集合类型 [#collection-types]

Nino 还支持由上述类型组成的集合，其中 `T`、`TKey` 和 `TValue` 都是可序列化类型：
- `T[]`、`List<T>`、`HashSet<T>`、`ICollection<T>`
- `Dictionary<TKey, TValue>`、`IDictionary<TKey, TValue>`
- `Span<T>`、`ArraySegment<T>`

<Callout type="warn" title="字典子类必须声明公开索引器">

从字典派生的类型**必须**声明一个公开的索引器，**否则不会为它生成序列化代码**：

```csharp title="MultiMap.cs"
public class MultiMap<T, K> : SortedDictionary<T, List<K>>
{
    public new List<K> this[T key] // [!code highlight]
    {
        get
        {
            if (!TryGetValue(key, out List<K> value))
            {
                value = new List<K>();
                Add(key, value);
            }

            return value;
        }

        set
        {
            if (value.Count == 0)
            {
                Remove(key);
            }
            else
            {
                base[key] = value;
            }
        }
    }
}
```

</Callout>

### 嵌套类型 [#nested-types]

可序列化类型可以任意嵌套，例如：
- `List<Dictionary<int, SampleStruct>>[]`，其中 `SampleStruct` 是可序列化类型
- `Dictionary<int[], List<bool>[]>`
- `IDictionary<string, IList<List<bool>[]>[]>[]`

### 多态类型 [#polymorphic-types]

Nino 支持序列化和反序列化多态类型。涉及的每个类型（接口、基类或派生类）都要标上 `[NinoType]`：

```csharp
[NinoType] // [!code highlight]
public class BaseClass
{
    public int Id;
}

[NinoType] // [!code highlight]
public class DerivedClass : BaseClass // [!code highlight]
{
    public string Name;
}
```

把 `DerivedClass` 当作 `BaseClass` 序列化时，Nino 会写入 `DerivedClass` 的全部字段和属性，反序列化得到的仍然是 `DerivedClass`。

因此 `BaseClass` 的集合里可以随意混放各种子类，每个元素读回来都是它的真实类型：

```csharp
var list = new List<BaseClass>
{
    new BaseClass { Id = 1 },
    new DerivedClass { Id = 2, Name = "Nino" }
};
var bytes = Serializer.Serialize(list);
Deserializer.Deserialize(bytes, out List<BaseClass> result); // [!code highlight]
// result[0] 是 BaseClass，result[1] 是 DerivedClass
```

### 抽象类和接口 [#abstractions]

Nino 支持序列化和反序列化接口与抽象类。接口或抽象类本身，以及实现它的每个类或结构体，都要标上 `[NinoType]`：

<Tabs items={["接口", "抽象类"]}>
<Tab value="接口">

```csharp
[NinoType] // [!code highlight]
public interface IBase
{
    int A { get; set; }
}

[NinoType] // [!code highlight]
public class Impl : IBase // [!code highlight]
{
    public int A { get; set; }
}

[NinoType] // [!code highlight]
public struct ImplStruct : IBase // [!code highlight]
{
    public int A { get; set; }
}
```

</Tab>
<Tab value="抽象类">

```csharp
[NinoType] // [!code highlight]
public abstract class Base
{
    public int A { get; set; }
}

[NinoType] // [!code highlight]
public class Derived : Base // [!code highlight]
{
    public int B { get; set; }
}
```

</Tab>
</Tabs>

由于 Nino 支持多态，通过接口或抽象类序列化的实现类会保留类型信息，反序列化时会还原对象的真实类型。
