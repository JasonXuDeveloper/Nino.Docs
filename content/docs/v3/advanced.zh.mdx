本页介绍已序列化类型的改名、字符串编码、哪些修改不影响读取旧数据，以及自定义构造函数。

## 类型改名 [#former-name]

从 v3.2.2 起，类型可以改名或移到别的命名空间，仍然能读取用旧名称序列化的数据。在 v3.2.2 之前，修改类型名或命名空间会导致旧数据反序列化失败。

给改名后的类型加上 `[NinoFormerName]`，填入它旧的完整名称（含命名空间）。

<Callout type="info" title="旧名称从哪里找">

从旧版本生成的 `NinoTypeConst.g.cs` 中复制旧名称即可。泛型类型只需要填旧的类型名和命名空间，不要带类型参数。

```csharp title="NinoTypeConst.g.cs"
// <auto-generated/>

using System;

namespace Nino.UnitTests.NinoGen
{
    public static class NinoTypeConst
    {
        ...
        // global::Nino.UnitTests.Generic<int> // [!code highlight]
        public const int Nino_UnitTests_Generic_int_ = -388704858;
        // global::Nino.UnitTests.Generic<string> // [!code highlight]
        public const int Nino_UnitTests_Generic_string_ = -1996567692;
        // global::ListElementClass2Renamed // [!code highlight]
        public const int ListElementClass2Renamed = 329143115;
        ...
```

</Callout>

### 示例 [#former-name-example]

```csharp
[NinoType]
[NinoFormerName("global::Nino.UnitTests.Generic")] // [!code highlight]
public class Generic<T> // [!code --]
public class GenericRenamed<T> // [!code ++]
{
    ...
}

[NinoType]
[NinoFormerName("global::ListElementClass2")] // [!code highlight]
public class ListElementClass2 // [!code --]
public class ListElementClass2Renamed // [!code ++]
{
    ...
}
```

## 字符串编码 [#string-encoding]

默认情况下，Nino 以 UTF-16 写入 `[NinoType]` 的字符串成员。给成员标上 `[NinoUtf8]` 就改为 UTF-8，序列化后的数据大小能减半。

<Callout type="warn">

使用 UTF-8 后，这些成员的序列化和反序列化会慢大约 5% 到 10%。

</Callout>

<Callout type="info">

`[NinoUtf8]` 标在非字符串成员上时会被忽略。

</Callout>

### 示例 [#string-encoding-example]

```csharp
[NinoType]
public class StringData
{
    [NinoUtf8] public string Str; // [!code highlight]
    [NinoUtf8] public bool ShouldHaveNoEffect;
}
```

## 版本兼容 [#version-compatibility]

对已序列化的类型做哪些修改后，现有数据仍然可读：

| 修改 | 是否允许 |
| --- | --- |
| **重命名**已序列化的字段或属性（成员顺序或 `[NinoMember]` 中的 `id` 保持不变） | 允许 |
| 把成员（**非托管**结构体）**改成**内存大小相同的**非托管**结构体（`int` → `uint`、`int` → `float`、`List<long>` → `List<double>`、`List<int[]>` → `List<float[]>`） | 允许 |
| 把成员**改成**它的**基类或派生类** | 允许 |
| 在类型**末尾添加**成员 | 仅在定义了 `WEAK_VERSION_TOLERANCE` 时允许 |
| **删除**已序列化的字段或属性 | 不允许 |

在末尾添加成员的方法：使用自动收集（`[NinoType]`）时，把新成员声明在已有成员的最后一个之后；使用 `[NinoType(false)]` 和 `[NinoMember(id)]` 时，给新成员一个排在已有成员之后的 `id`（Nino 按 `id` 从小到大排列成员）。在项目中定义 `WEAK_VERSION_TOLERANCE` 符号即可开启此功能。

<Callout type="warn">

定义了 `WEAK_VERSION_TOLERANCE` 的项目无法反序列化未定义该符号的项目序列化的数据，反之亦然。

</Callout>

## 自定义构造函数 [#custom-constructors]

Nino 可以通过你指定的构造函数来反序列化对象。如果想在反序列化时执行额外的逻辑，比如初始化不参与序列化的字段或属性，就可以用它。对于 record，Nino 既可以用主构造函数，也可以用自定义的构造函数。

### 使用方法 [#usage]

下面的特性会把成员 `Field1, Field2, ...` 作为参数，传给它所标记的构造函数：

```csharp
[NinoConstructor(nameof(Field1), nameof(Field2), ...)]
```

不加这个特性时，Nino 会自己选构造函数：

| 类型 | 默认使用的构造函数 |
| --- | --- |
| `record` | 主构造函数。 |
| `class` | **第一个 public 构造函数**，它要么没有参数，要么所有参数都与要反序列化的字段或属性同名。 |
| `struct` | 无参构造函数（结构体总有一个）。 |

默认选的构造函数不合适时，用 `[NinoConstructor]` 标记要用的那一个。

### 限制 [#restrictions]
- 构造函数必须是 `public` 的。
- 参数个数必须与 `[NinoConstructor]` 中列出的名称个数相同。
- `[NinoConstructor]` 中的每个名称都必须与类、结构体或 record 中会被反序列化的字段或属性同名（忽略大小写），也就是说这些成员本身必须参与序列化。
- `[NinoConstructor]` 中的名称就是按顺序传给构造函数的成员。

### 示例 [#constructor-examples]

<Tabs items={["多个构造函数", "主构造函数", "不用主构造函数"]}>
<Tab value="多个构造函数">

```csharp
[NinoType]
public record SimpleRecord
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    public SimpleRecord()
    {
        Id = 0;
        Name = string.Empty;
        CreateTime = DateTime.MinValue;
    }

    [NinoConstructor(nameof(Id), nameof(Name))] // [!code highlight]
    public SimpleRecord(int id, string name)
    {
        Id = id;
        Name = name;
        CreateTime = DateTime.Now;
    }
}
```

</Tab>
<Tab value="主构造函数">

```csharp
[NinoType]
public record SimpleRecord2(int Id, string Name, DateTime CreateTime); // [!code highlight]

[NinoType]
public record SimpleRecord4(int Id, string Name, DateTime CreateTime) // 会使用这个 // [!code highlight]
{
    [NinoIgnore] public bool Flag;

    public int ShouldNotIgnore;

    // Nino 不会使用这个 // [!code highlight]
    public SimpleRecord4() : this(0, "", DateTime.MinValue)
    {
    }
}
```

</Tab>
<Tab value="不用主构造函数">

```csharp
[NinoType]
public record SimpleRecord5(int Id, string Name, DateTime CreateTime) // 不会使用这个 // [!code highlight]
{
    [NinoIgnore] public bool Flag;

    public int ShouldNotIgnore;

    // Nino 会使用这个，但反序列化时主构造函数的值会被丢弃，不推荐
    [NinoConstructor] // [!code highlight]
    public SimpleRecord5() : this(0, "", DateTime.MinValue)
    {
    }
}
```

</Tab>
</Tabs>

类和结构体同样可以使用自定义构造函数：

<Tabs items={["结构体使用有参构造函数", "类使用有参构造函数"]}>
<Tab value="结构体使用有参构造函数">

```csharp
[NinoType]
public struct SimpleStruct
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    // 反序列化时用这个构造函数创建结构体
    [NinoConstructor(nameof(Id), nameof(Name), nameof(CreateTime))] // [!code highlight]
    public SimpleStruct(int a, string b, DateTime c)
    {
        Id = a;
        Name = b;
        CreateTime = c;
    }
}
```

</Tab>
<Tab value="类使用有参构造函数">

```csharp
[NinoType]
public class SimpleClassWithConstructor
{
    public int Id;
    public string Name;
    public DateTime CreateTime;

    // 不需要 [NinoConstructor]：这是唯一的 public 构造函数，
    // 参数也与成员同名，Nino 会自动使用它
    public SimpleClassWithConstructor(int id, string name, DateTime createTime) // [!code highlight]
    {
        Id = id;
        Name = name;
        CreateTime = createTime;
    }
}
```

</Tab>
</Tabs>
