## Nino 是什么？ [#what-is-nino]

Nino 是高性能的 C# 二进制序列化库。给类型加上 `[NinoType]`，源生成器就会在你写代码的同时生成它的序列化代码。运行时调用生成的 `Serializer` 和 `Deserializer` 即可：

```csharp title="Program.cs"
[NinoType]
public class ObjClass
{
    public int Id;
    public string Name { get; set; }
}

byte[] bytes = Serializer.Serialize(obj);
Deserializer.Deserialize(bytes, out ObjClass copy);
```

## 为什么选 Nino v3 [#why-nino-v3]

- **相比 v2 的一大步。** 总体性能比 Nino v2 提升约 **25%**。
- **可能是最快的。** 比 MemoryPack 快 **30%** 到 **120%**，比 MessagePack 快 **360%** 到 **900%**。详见[基准测试](/zh/docs/v3/perf)。
- **生来全能。** 支持记录、多态、泛型、跨项目引用等功能。详见[支持的类型](/zh/docs/v3/types)。
