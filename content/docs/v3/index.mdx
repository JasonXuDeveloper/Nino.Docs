## What Is Nino? [#what-is-nino]

Nino is a high-performance binary serialization library for C#. Mark a type with `[NinoType]`, and a source generator writes its serialization code while you write your program. At run time you call the generated `Serializer` and `Deserializer`:

```csharp title="Program.cs"
[NinoType]
public class ObjClass
{
    public int Id;
    public string Name { get; set; }
}

byte[] bytes = Serializer.Serialize(obj);
Deserializer.Deserialize(bytes, out ObjClass copy);
```

## Why Nino v3 [#why-nino-v3]

- **A leap from v2.** Overall performance is about **25%** faster than Nino v2.
- **Plausibly the best.** **30%** to **120%** faster than MemoryPack, and **360%** to **900%** faster than MessagePack. See [Benchmarks](/en/docs/v3/perf).
- **Born to be versatile.** Supports records, polymorphism, generics, cross-project references and more. See [Supported Types](/en/docs/v3/types).

## Newer Version [#newer-version]

Nino v3 is archived. The current version is [Nino v4](/en/docs/v4), a rewrite with a new binary format that v3 cannot read. See [What's New in v4](/en/docs/v4/whats-new) and [Migrating from v3](/en/docs/v4/migration).
